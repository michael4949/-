# 在 Mac 上安装并使用 Mnemo（零基础保姆版）

全程约 15 分钟。你只需要：装两个免费软件 → 下载代码 → 双击启动。
**不用懂代码，照着点就行。**

---

## 第 1 步：装 Python（双击安装，免费）

1. 用 Safari 打开 👉 https://www.python.org/downloads/
2. 点页面上那个黄色大按钮 **「Download Python 3.x.x」**
3. 下载完，在「下载」里打开那个 `.pkg` 文件
4. 一路点 **继续 → 同意 → 安装**（可能要输你的开机密码）
5. 装完关掉就行，不用打开它

## 第 2 步：装 Node.js（双击安装，免费）

1. 打开 👉 https://nodejs.org
2. 点那个写着 **「LTS」** 的推荐版按钮下载
3. 打开下载的 `.pkg`，同样一路点 **继续 → 安装**

> 这两个是让 Mnemo 能跑起来的基础工具，装一次以后就不用再装了。

## 第 3 步：下载 Mnemo 的代码

**最简单：** 直接点这个链接下载（会得到一个 zip）👇
`https://github.com/michael4949/-/archive/refs/heads/claude/tender-ride-LfoB7.zip`

下载完：
1. 在「下载」文件夹里**双击那个 zip**，它会解压出一个文件夹
2. 把这个文件夹**拖到桌面**，并改名叫 `mnemo`（方便找；可选）

> 备选方式：打开 https://github.com/michael4949/- → 左上角分支按钮选
> `claude/tender-ride-LfoB7` → 绿色 **Code** 按钮 → **Download ZIP**。

## 第 4 步：第一次双击放行（只需一次）

1. 打开桌面上的 `mnemo` 文件夹
2. 找到里面的 **`start-mac.command`** 文件
3. **右键点它 → 选「打开」→ 再点一次「打开」**
   （第一次 Mac 会拦一下问你确定吗，这样点就放行了；以后能直接双击）

## 第 5 步：填 Claude 的钥匙，然后它自己全启动

双击/打开 `start-mac.command` 后，会跳出一个黑色文字窗口。它会问你要 Claude 的 key：

1. 打开 👉 https://console.anthropic.com ，注册/登录
2. 左边 **API Keys → Create Key**，复制那串 **以 `sk-ant-` 开头**的字符
3. 回到黑窗口，**粘贴进去，按回车**
   （暂时不想花钱？**直接按回车**，先用「离线模式」体验记事/回忆）

然后它会自动装好、启动、并打开浏览器到 **http://localhost:3000** —— 看到控制台就成了 🎉

---

## 以后怎么用

- **打开**：双击 `start-mac.command`
- **关闭**：回到那个黑窗口，按 **Control + C**

## 关于花钱（说清楚）

- Claude 的 API 是**按用量付费**的（和你在用的 Claude 订阅是两个账户）。
- 先在 console 里充 **$5** 就能玩很久；用便宜模型一次对话往往几分钱。
- **离线模式不花钱**，但只会记事 / 回忆 / 自动学技能，不能回答任意问题。
