## 二、写作流程

每集严格按 v2 规范（`improvements/v2-feedback-spec.md`）执行，落实客户 12 条红线：

1. 信息量必须爆满，禁止留白靠脑补
2. 闪回必须有前置语境
3. 形容词必须具体可视
4. 高度套路必须用 OS 补背景
5. 关键身份必须明示
6. 王翠芬骗局逻辑：先"亲娘+失忆" → 让女主自我脑补 → 后期"仙姑下凡"
7. 重生后女主第一情绪是"悔恨"，不是兴奋
8. 禁止奶声奶气装小姑娘
9. 场景必须形成"小闭环"，禁止反派自说自话
10. 单集只服务一个目标
11. 困境 + 金手指必须反复强调
12. 每集必须闭环爽一次
