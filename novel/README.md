## 二、写作引擎工作流

每写一集，按 6-Agent Pipeline：

1. **大纲 Agent**：从 `outline/episodes-detailed.md` 拉本集纲要
2. **写作 Agent**：拉 `story-bible/characters.md` 中相关角色 + `world.md` 中相关场景，输出 1800-2500 字剧本
3. **风格 Agent**：润色为短剧节奏（短句、对话密、留白）
4. **爽点 Agent**：对照 `shuangdian-pool.md` 校验本集爽点是否命中节奏表
5. **审校 Agent**：检查人设是否一致、时间线是否冲突、伏笔是否乱埋
6. **钩子 Agent**：检查集末是否留悬念
7. **更新 Bible**：把本集新事件写回 `characters.md` 的"已知事件"和 `foreshadowing.md` 的"状态"
