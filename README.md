# 税擎 TaxPilot · AI 税务自动申报智能体 🛡️

> 面向**集团企业**的 AI 税务自动申报中枢。一句话：**一个会自己干活、还能把每一步讲清楚的税务智能体。**

连接账务与数电发票 → 自动归集与分类 → 分税种实时测算 → 识别**金税四期风险**与**节税机会** → 生成可一键申报的税表 → **人在环路审批**后申报。全程**可视化、可溯源、可留痕**。

配色为**浅色专业风**，数据驱动、克制、可信。

```
连接数据源 → 归集本期数据 → 发票验真匹配 → 分税种测算 → 纳税调整与优惠
   → 生成申报表 → 金税四期风险体检 → 节税/退税扫描 → 生成审批单（等你确认）
```

## 为什么能「超越同类」

调研了 TaxGPT、Instead、Thomson Reuters Ready to Review（海外）与金蝶 AI 星辰、税友、百望云（国内）后，我们把它们的共性短板做成了差异化卖点：

| 同类的痛点 | 税擎的打法 |
|---|---|
| 🕳️ **黑箱**：只给结果，不讲「为什么」 | **可视化 Agent 执行时间线**；申报表每一行都能**溯源**到发票/账务/系统 |
| 😴 **被动**：等你来操作 | **主动税务雷达**：实时测算应纳税额、临期倒计时、节税机会量化 |
| 🧩 **割裂**：申报 / 风险 / 节税各做各的 | **申报 + 金税四期风险 + 节税优化** 三合一驾驶舱 |
| 😰 **信任**：全自动让人不敢用 | **人在环路审批关卡**（制单→复核→审批→申报）+ **审计留痕** |

## 模块一览

- **税务驾驶舱** — 集团税负总览、近 6 月趋势、税种结构、各主体税负率体检、待办与风险/机会概览。
- **AI 自动申报**（核心）— 一键启动，9 步全自动跑完并动画展示；实时进度环、关键产出与工作日志；**每步可展开看推理与数据来源**。
- **申报工作台** — 全集团申报事项表；点开任一事项查看**国标申报表明细（可溯源）**、审批流与审计留痕；支持单项/批量**复核、审批、一键申报至电子税务局**。
- **风险中心** — 金税四期风险扫描、税负率体检、智能体处置建议（采纳/忽略）。
- **节税优化** — 政策智能匹配：研发加计扣除、增值税留抵退税、高新/小微优惠、自贸港奖补，已量化收益与把握度。
- **发票中心** — 数电发票进销项、验真匹配、认证抵扣进度、异常进项发票转出。
- **智能税务副驾** — 悬浮对话助手，基于本期真实数据回答「这笔税为什么这么多 / 还有哪些没申报 / 有哪些节税机会 / 谁有风险」。

> 演示对象为某大型集团（以 **XXX集团** 代称，下辖 6 家法人主体），所属期 **2026 年 5 月**。

## 技术栈

纯前端，零后端，可直接静态托管。

| 技术 | 用途 |
|---|---|
| React 19 + TypeScript + Vite | 应用框架与构建 |
| Tailwind CSS（浅色设计系统） | 配色/排版（`index.html` 内置主题与品牌色） |
| Recharts | 趋势、税种结构等可视化 |
| lucide-react | 图标 |

代码结构：

```
App.tsx                 应用外壳（侧栏 + 顶栏 + 视图路由 + 申报状态）
types.ts                税务领域类型
data/mockData.ts        演示数据（主体/申报/风险/节税/发票/趋势 + 派生 KPI）
components/tax/
  Sidebar / Topbar      导航与主体切换、申报倒计时
  Dashboard             税务驾驶舱
  AutoFileAgent         AI 自动申报（动画时间线，核心）
  FilingWorkspace       申报工作台 + 税表抽屉 + 审批流 + 审计留痕
  RiskCenter            风险中心
  OptimizationCenter    节税优化
  InvoiceCenter         发票中心
  Copilot               智能税务副驾（对话）
  ui.tsx                通用 UI 组件与格式化工具
```

## 运行

```bash
npm install
npm run dev        # http://localhost:3000
npm run build      # 产物在 dist/，可部署到任意静态托管
```

无需任何密钥或环境变量即可完整体验（智能体的归集/测算/对话均为本地确定性逻辑驱动的高保真演示）。

## 说明与边界

- 这是一个**高保真交互原型**：所有金额、主体、发票均为**虚构样例**，用于演示产品形态与体验。
- 真实落地需对接 ERP / 数电发票平台 / 电子税务局申报接口，并由税务负责人对申报结果负责。**申报前请人工复核。**
