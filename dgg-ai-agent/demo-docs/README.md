八个场景各两份，共 16 份。

## 怎么用

1. 首页点进对应场景，右侧对话坞点回形针，选这个场景的文件。
2. 传完等两三秒，AI 会把读到的内容说出来，并顺手改一处屏上的数或跳一屏。
3. 「传哪一屏」写着「进模块第一屏」的，进去就能传；其余屏也能传，回答会换成那一屏的口径。
