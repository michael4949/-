# 工博会首页展板 · 生图提示词

> 用途：原型首页整屏底图（和杭州版一样，图上只盖透明热区，不重绘）。
> 尺寸：2000×1125（16:9），主屏 1920×1080 等比缩放。
> 参考：杭州版 `prototype/assets/home-board.webp`。沿用它的做法——写实卡通人物头像代表智能体、中央等轴测场景图、卡片式信息层、印刷级排版；但构图和配色做差异化，见下方「差异化要点」。
> 图上的文字生成后通常会有错字，正式用时**所有文字由前端叠字**，生图只要留出版位；提示词里的文字是给模型定位的。

## 差异化要点（相对杭州版）

| | 杭州版 | 工博会版 |
|---|---|---|
| 底色 | 米白 + 暖金花纹边框 | 冰川蓝到银白的冷调渐变，无花纹边框；点缀一条琥珀金光带作为唯一暖色 |
| 构图 | 左中右三列对称，人物卡分列两侧 | 左右非对称：左 55% 是一座等轴测智能工厂，右 45% 是 2×3 六张场景卡；方法论三卡横排在工厂上方 |
| 人物 | 六位商务人物半身像，胸前分别有名牌 | 同样写实卡通半身像，但穿着换成工厂场景：工装、安全帽、工程师衬衫、财务西装，站在各自的场景前 |
| 中央场景 | 企业园区（办公、车间、仓库、门店） | 单一座**汽配智能工厂**：数控加工中心、冲压线、装配线、立体仓库、办公楼，四条发光数据流从 ERP / MES / WMS / Excel 四个节点汇入 |
| 右栏 | 企业、积分、微信二维码 | 取消积分；右下角只留一块「扫码预约 15 分钟现场演示」二维码位 |
| 底栏 | 六档价格 | 4 大优势 + 8 个适用行业胶囊 |
| 质感 | 温暖、亲和 | 克制、精密、有科技公司年报的高级感 |

## 生成后的处理

1. 出 3–4 张候选，看工厂的透视和六张人物卡的比例，选一张做底。
2. 用图像编辑把图上所有文字抹平（保留版位），文字由前端叠加，字体、字号与物料统一。
3. 人物头像若不满意，可单独生成 6 张圆形头像再合成（提示词见下），保证六人风格一致。
4. 导出 2000×1125 WebP，替换 `prototype/assets/home-board.webp`，热区坐标按新图重新量。
