# 工博会现场高保真原型方案（薯片AI智能体 · CIIF 2026 · 6.2H-B018）

> 依据：已定稿的两张物料（易拉宝 + 单页正反面）。原型的任务是把海报上的每一句话、每一个数字变成屏幕上能点、能看、能带走的东西。
> 基线：杭州展会原型（分支 `origin/claude/great-bardeen-jgeon1`，目录 `dgg-ai-agent/prototype`），单文件 `dist/index.html`，双击即开，断网可用。本次是**改造**，不是重写。

## 一、先定原则：海报说什么，屏幕就演什么

物料上的内容已经定了，原型必须和它逐句对得上，否则销售讲一套、屏上是另一套。对照如下：

| 物料上的内容 | 原型里对应的东西 |
|---|---|
| 主标题「让AI成为工厂的经营合伙人」 | 待机页与首页主视觉，同一句话、同一套配色 |
| 副标题「连接ERP、MES、WMS与Excel，覆盖订单、生产、库存、资金与经营决策」 | **新增「数据接入」屏**：四个数据源卡片（ERP / MES / WMS / Excel），点一下显示接入状态和读到的表；六大场景全部从这一屏进入 |
| 方法论「AI全域获客 · 场景优先级规划 · 投入产出测算」 | 首页第一行三张卡，直接进模块 04 / 02 / 03 |
| 182 个场景库 / 4 维评估模型 / 24 期现金流 / 3 档情景 | 场景排序屏和 ROI 屏上，这几个数字要**原样出现在标题或角标里**，销售指着念 |
| 六大经营场景智能体（新名字） | 六个模块改名换标（见第三节），每个模块最后一屏输出海报上写的「交付物」 |
| 「扫码预约 15 分钟现场演示」 | 一条固定的 15 分钟演示动线（见第四节），屏上每一步有「下一步」引导 |
| 「专家咨询」二维码 | 每个交付物屏右下角常驻同一个码，文案统一为「扫码领取本报告 · 专家咨询」 |
| 4 大优势：全域获客 / 行业定制 FDE 入企 / 本地运行 / 私有化部署 | 待机页轮播 + 首页底栏；「本地运行」现场可当场拔网线证明 |
| 适用行业 8 个 | 行业下拉只保留这 8 个制造细分，去掉财税、医疗、电商、教育等 |

## 二、展台硬件与站位

工博会专区是统一搭建，标配只有 55 寸电视（18㎡ 一台，36㎡ 两台），不一定是触摸屏。所以站位设计要以「一台不可触摸的电视 + 一台销售操作的笔记本 + 一台可触摸的平板」为默认，多出来的屏再加。

| 站位 | 设备 | 原型模式 | 用途 |
|---|---|---|---|
| A 主屏 | 55 寸电视，HDMI 接笔记本 | `?station=tv` | 无人时放**待机轮播**；有人时销售用笔记本操作，屏上走 15 分钟演示 |
| B 自助 | iPad 或触摸一体机（自带） | `?station=pad` | 观众自己勾痛点、看场景排序、留资预约；字号放大，单手可操作 |
| C 接待 | 笔记本本身 | `?station=desk` | 销售深聊时用，可开任意模块，带对话坞和上传文档 |

- 三种模式共用一个 `index.html`，只是入口页和字号档不同，和杭州版的 `?station=1/2/3` 机制一样。
- 分辨率按 1920×1080 做主屏，iPad 按 2048×1536 横屏校验，笔记本按 1600×900 兜底。
- 电视如果不能接笔记本，只能放 U 盘视频：另出一段**待机页录屏 MP4**（60 秒循环），这是备选，不是主方案。
- 全程断网设计不变；预约表单落本地存储，每晚导出 CSV。

## 四、15 分钟演示动线（原型「下一步」引导按这条走）

海报承诺的是「15 分钟现场演示」，原型要保证销售照着「下一步」点就能在 15 分钟内走完，不卡壳。

| 时间 | 屏 | 演什么 | 落点 |
|---|---|---|---|
| 0–1 分 | 待机 → 首页 | 主标题、六大场景一览；问观众做哪一行，切行业 | 首页 |
| 1–3 分 | 数据接入 | 点 ERP / MES / WMS / Excel 四张卡，显示读到订单表、报工表、库存表、科目余额表；一句话「不换系统，读您已有的数」 | 接入屏 |
| 3–6 分 | 场景优先级规划 | 勾 3–5 条痛点，实时重排；指着角标念「182 个场景、4 维模型」 | 排序清单 |
| 6–8 分 | 投入产出测算 | 三档情景切换，回收期变化 | 测算表 |
| 8–13 分 | 一个场景深潜 | 按观众身份选：老板 → AI经营指标分析；厂长 → AI工序级排程插单；财务 → AI现金流；销售负责人 → AI全域获客 | 该场景交付物 |
| 13–15 分 | 交付物 + 预约 | 「扫码领取本报告」，顺势填预约表单（企业、行业、规模、关注场景、手机） | 线索入库 |

- 引导层沿用杭州版「每屏常驻下一步 + 跟随式箭头」，但路径改成上面这条；深潜环节四选一，在首页按行业和身份预选。
- 观众多、时间紧时有 5 分钟短版：首页 → 接入 → 插单三方案 → 预约。

## 五、待机页与自助模式

**待机页（电视无人时循环，约 45 秒一轮）**
1. 主标题「让AI成为工厂的经营合伙人」+ 副标题
2. 方法论三张卡的数字逐个点亮（182 / 4 / 24 / 3）
3. 六大场景卡轮流高亮，每张停 3 秒，显示交付物
4. 4 大优势
5. 「扫码预约 15 分钟现场演示」+ 二维码

**自助模式（平板，观众自己玩）**
- 只开放三步：选行业 → 勾痛点 → 看排序，最后一屏留资。
- 每步一屏，按钮高度不小于 64px，不出现表格和小字。
- 60 秒无操作自动回第一屏并清空。
- 排序结果可以「发到微信」，实际是生成带参数的二维码，观众扫码后由企业微信活码承接。

## 六、线索收集

专区的核心目标是线索，原型要把留资做成动线的自然终点，而不是单独的表单。

- **表单字段**：企业名称、细分行业（8 选 1）、人员规模（5 档）、最关注的场景（6 选 1）、手机号、同意隐私条款。字段与 AI获客模块「展会线索」样本的 7 个字段对齐，展后可以直接导入自家产品做分级分派。
- **存储**：本地 IndexedDB，每条带时间戳、站位、演示到哪一屏；每晚一键导出 CSV。
- **渠道参数**：电视演示码 `CIIF2026-演示屏`，平板码 `CIIF2026-自助`，海报码 `CIIF2026-海报`，分开统计。
- **隐私**：表单页底部固定一行「信息仅用于本次展会后联系，本机离线保存」。

## 七、展前必须处理的内容风险

这些不是原型功能，但演示时一定会撞上。

1. **「高意向线索占比提升 5%」**：这是效果类数字，样本数据里没有，原型只能展示「高意向线索占比」的当前值。要么公司给出口径和出处，原型做成「接入前 / 接入后」对比；要么原型只显示当前值，5% 留在海报由销售解释。
2. **MES / WMS 接入**：现有模块只读 Excel 和 ERP 导出表，没有 MES、WMS 的读取逻辑。接入屏上这两张卡先做成「已接入」的模拟状态，读的是报工表和库存表样本；话术要说清是导出表，不是实时接口。
3. **场景排序推荐了做不出的场景**：02 给制造企业排出的 13 个场景里，报价自动生成、来料质检、预测性维护、能耗分析等 6 个在对应模块里没有实现。展前改 `sectors/mfg.json` 的模块映射，把这几条标为「合作生态」，否则观众点进去是空的。
4. **报告封底「展位号 undefined」**：`module-01.js` 读的字段在 `report-text.json` 里不存在，一并修。
5. **「同行排名」话术**：01 的参考带是估算值，屏上和话术只能说「参考带」，不能说「排第几」。
