# 企业AI成熟度评估智能体 v3.0 · 使用说明

本地版单文件应用：**双击即用，无需安装、无需服务器**。由 Claude（Opus 4.8）大模型本地直连驱动。

## 一、文件清单

| 文件 | 作用 |
|---|---|
| `企业AI成熟度评估智能体_v3.0.html` | 主程序，双击用浏览器打开 |
| `config.js` | 本地配置文件（API Key / 模型 / 联网开关），**必须与 HTML 同目录** |
| `使用说明.md` | 本文档 |

## 二、首次配置（只需一次）

1. 前往 <https://console.anthropic.com> → **API Keys**，创建一个 Key（以 `sk-ant-` 开头）；
2. 用记事本 / VS Code 打开 `config.js`，把 Key 粘贴到 `apiKey: ""` 的引号内，保存；
3. 双击打开 HTML，点「开始评估」即可。

> 不想编辑文件？直接打开 HTML 点「开始评估」，会弹出一次性配置窗口，把 Key 粘贴进去即可（保存在本机浏览器中，之后不再询问）。
>
> **安全性**：Key 只存在您本机（config.js 或浏览器本地存储），页面直连 Anthropic 官方接口 `api.anthropic.com`，不经过任何第三方服务器。

## 三、使用流程

六个环节自动引导，全程以**点选选项**为主（每个问题都配有选项，也可随时打字补充）：

```
① 开场引导 → ② 企业画像 → ③ 材料解读(可跳过) → ④ 六维诊断 → ⑤ 研判确认 → ⑥ 报告生成
```

- 每完成一个环节，对话中会出现**环节过渡卡片**，AI 会主动小结并提出下一环节的第一个问题，您无需思考"接下来该说什么"；
- 顶栏有**整体进度条**和「跳到下一环节 ➝」按钮，可随时快进；
- 第③环节可上传战略 PPT 截图、数据架构图、年报 PDF 等（最多 3 个），AI 会解读后纳入评估；
- 中途关闭页面没关系：再次打开会出现「**继续上次评估**」，从断点续评；
- 报告生成后，可在对话框直接输入调整要求（如"30 天计划更聚焦数据治理"）**微调报告**，也可点「重新评估」从头开始。

## 四、评估报告（共 13 页）

封面 → 关于本报告(方法论+目录) → 执行摘要(关键指标卡) → 评估总览(雷达图+等级阶梯+**六维行业对标**) → 六维深度诊断 ×3 页(每维度：深度分析 / 3 项子能力评分 / 优势·短板·风险·30天速赢) → 核心发现(SWOT) → 差距分析与**量化收益预估** → 30/90/180 天行动路线图+保障机制 → 解决方案组合 → 附录(等级与维度定义、声明) → 封底。

- 报告配色与封面图自动贴合客户行业气质；
- 点右上角「⤓ 下载 PDF 报告」导出高清 PDF（若浏览器拦截，会自动转为打印→另存为 PDF）。

## 五、常见问题

| 问题 | 处理 |
|---|---|
| 点开始后提示连接问题 | 检查 config.js 里的 Key 是否正确、账户额度是否充足、网络能否访问 api.anthropic.com（部分地区需代理） |
| 提示 429 / 服务繁忙 | 程序会自动退避重试 2 次；仍失败请稍候点「重试上一步」 |
| 报告生成失败 | 点「重新生成报告」即可，已采集的访谈信息不会丢失 |
| PDF 导出按钮无反应 | PDF 组件走 CDN 加载，需联网；离线时会自动改用浏览器打印 |
| 想换模型 | 编辑 `config.js` 的 `model` 字段（默认 `claude-opus-4-8`） |
| 想关闭联网检索 | `config.js` 中 `enableWebSearch: false` |

## 六、v3.0 相对 v2.0 的改进

1. **本地版**：去掉了"打开页面输入 API Key"的设计，改为 config.js 一次配置永久生效；
2. **不再翻页/闪屏**：重写渲染层为增量更新 + 流式逐字输出，AI 回复实时显示，只在您位于底部时才跟随滚动；
3. **每问必有选项**：提示词铁律 + 六维内置题库 + 客户端兜底（即使模型漏发选项，也会自动补"参考选项/帮我判断/跳过"三个辅助按钮）；
4. **环节衔接**：AI 在同一条回复内完成"小结上环节→宣布下环节→提出第一问"，配合过渡卡片、进度条、侧边栏操作提示与"跳到下一环节"按钮；
5. **报告升级**：从 5 页扩展到 13 页专业咨询报告（新增方法论、目录、关键指标、行业对标、子能力评分、风险与速赢、SWOT、差距分析、量化收益、保障机制、附录），并改用结构化输出（JSON Schema）保证报告数据 100% 可解析；
6. **自检补充**：断点续评、错误自动重试与降级（429/529 退避、工具不可用自动降级）、上传选项直接唤起文件选择器、报告微调、修复已失效的封面图源、支持 pause_turn 长检索续传、思考/检索状态实时提示。
