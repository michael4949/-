# 中国通信服务集团 · 智能体展示中心

专门为 **中国通信服务集团（中国通服 / CHINA COMSERVICE）** 定制的智能体展示前端页面，
用于挂载到智能体 showcase 平台（`http://123.56.172.85:3000/showcase`）。

![配色](https://img.shields.io/badge/%E4%B8%BB%E8%89%B2-%E9%80%9A%E6%9C%8D%E7%BA%A2%20%23E60012-e60012) ![辅色](https://img.shields.io/badge/%E8%BE%85%E8%89%B2-%E8%97%8F%E8%93%9D%20%2315213B-15213b)

## 特性

- **纯静态单文件**：只有一个 `index.html`，零外部依赖（无 CDN、无字体外链、无构建步骤），内网/离线环境可直接使用
- **通服品牌配色**：通服红 `#E60012` 主色 + 藏蓝 `#15213B` 辅色，顶栏含红色飘带球体标识与"中国通信服务 / CHINA COMSERVICE"字标，页脚含"重信赖 · 尚智慧 · 利万物"文化理念
- **分类可点击**：吸顶分类筛选条（全部 / 勘察设计 / 工程建设 / 智慧运维 / 数智政企 / 客户服务 / 经营管理），点击即筛选，附每类数量角标；另带关键词搜索
- **20 个预置智能体**：覆盖通服"规划设计—建设交付—运维保障—数智运营"全链条业务场景，卡片样式与 showcase 平台现有卡片风格一致（图标块 + 名称 + 分类标签 + 简介 + 地址 + 新标签页打开）
- 响应式布局，自适应大屏 / 笔记本 / 手机

## 部署

任选其一：

```bash
# ① Python（最简单，端口可换成 showcase 规划的端口，如 9021）
cd ccs-showcase && python3 -m http.server 9021

# ② Nginx：将 index.html 放入站点根目录即可

# ③ 不部署：直接双击 index.html 用浏览器打开也能完整运行
```

部署后在 showcase 平台（`http://123.56.172.85:3000/showcase`）新增一张卡片，
名称填「智能体展示中心」、公司填「中国通信服务集团」、地址填部署地址（如 `http://<服务器IP>:9021`）即可。

## 维护智能体清单

打开 `index.html`，所有数据集中在 `<script>` 顶部的 **数据配置区**：

```js
var CATEGORIES = [
  { id: "design", name: "勘察设计", color: "#2563eb" },
  // id 为分类标识，color 为该分类卡片图标的主题色
];

var AGENTS = [
  { name: "无线网络规划智能体",  // 智能体名称
    cat:  "design",             // 所属分类（对应 CATEGORIES 的 id）
    icon: "radio",              // 图标键名（见 ICONS 对象，已内置 20 种线性图标）
    desc: "基站选址与覆盖仿真…", // 一句话简介（卡片上最多显示两行）
    url:  "" },                 // 演示地址：填入后卡片可点击并显示"新标签页打开"；
                                // 留空则显示"演示环境部署中 / 敬请期待"
];
```

新增 / 修改 / 删除条目后刷新页面即可生效，分类计数、顶部统计数字均自动重算。
