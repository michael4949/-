关于

本页是「智能标书生成系统」的单文件离线版，把核心流水线（招标文件解析 → 需求/废标项抽取 → 企业知识库检索 → 多模块标书生成 → 合规审核 → 导出）移植到浏览器端，无需安装、不联网、双击即用，适合快速体验与分享。

五个步骤（对应完整版六大模块）

  1. 解析/抽取：正则规则识别项目信息、★/▲废标项、评分细则、技术参数、合同风险。
  2. 知识库检索：内置管道行业示例资料，关键词 BM25 检索 + 覆盖度重排序（完整版为向量+关键词混合检索）。
  3. 标书生成：按标书结构分模块，用领域模板 + 检索资料合成各章节。
  4. 审核校验：对照废标项逐条核验、检测占位符与空章节，给出合规度评分。
  5. 导出：一键导出 Word(.doc) / 打印为 PDF。

与完整版（Python）的差异

  • 单文件版仅支持文本/Markdown 输入；完整版支持 .docx / .pdf 解析（含表格）。
  • 单文件版为关键词检索；完整版为 向量 + 关键词混合检索 + 重排序。
  • 单文件版为模板生成；完整版可接入 本地大模型 Ollama，由多 Agent 并行生成，质量更高。
  • 导出：单文件版为 Word 兼容 .doc；完整版生成标准 .docx。
