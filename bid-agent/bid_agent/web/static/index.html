关于本系统

本系统基于「本地大模型 + Agent + RAG」架构，将标书编制从"数日鏖战"缩短到"数小时完成 + 人工最终确认"。 全流程在本地运行，数据不出域。

四层架构

  • 基础设施层：通过 Ollama 在本地运行大模型（CPU/GPU），未连接时自动降级为内置确定性引擎。
  • 向量化与检索层：企业私有知识库，向量检索 + 关键词检索（BM25）混合，并做重排序。
  • 智能体编排层：StateGraph（LangGraph 风格）编排「解析→抽取→检索→生成→审核→导出」。
  • 应用与交互层：本 Web 界面。

六大功能模块

  1. 招标文件解析（Word/PDF，含表格与结构）
  2. 招标需求智能抽取（NER / 废标项 / 评分细则 / 技术参数 / 合同风险）
  3. 企业知识库构建与检索
  4. 智能标书生成（多 Agent 分模块并行）
  5. 标书审核与校验（合规 + 完整性）
  6. 系统管理（知识库 / 任务 / 审计日志）
