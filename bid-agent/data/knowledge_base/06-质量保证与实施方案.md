# 质量保证体系与供货实施方案

## 一、质量保证体系
公司按 ISO 9001 建立覆盖原料采购、生产制造、检验试验、仓储运输、交付服务的全过程质量管理体系：
- 原材料入厂检验：球墨铸铁、PE100 原料均索证索票并抽检，不合格不投产；
- 过程控制：关键工序（离心铸造、退火、挤出、衬里、防腐）设质量控制点，做到首检、巡检、终检；
- 出厂检验：每批次进行外观、尺寸、力学性能、水压试验，100% 合格方可出厂；
- 第三方检测：定期委托具备 CMA/CNAS 资质的检测机构进行型式检验。

## 二、供货组织与进度
- 项目组织：成立由项目经理、技术负责人、质检员、物流专员组成的供货项目组；
- 生产排产：接到供货计划后 3 个工作日内排产，按里程碑分批供货；
- 物流配送：自有及合作运输车队，按现场需求计划配送到指定地点，附送货单与质保资料；
- 应急保障：储备一定安全库存，应对现场进度调整与紧急用料。

## 三、安全与文明
严格执行装卸、运输安全规范，管材堆放、吊装符合安全要求，配合业主与监理做好现场文明管理。

## 四、质量承诺
对所供产品质量负责，承诺所供货物为全新、未使用、符合招标技术要求的合格产品，材质、规格、标准与投标文件一致，绝不以次充好、以假乱真。
