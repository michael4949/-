# 主要产品技术参数

## 一、球墨铸铁管（离心铸造）
- 执行标准：GB/T 13295《水及燃气管道用球墨铸铁管、管件和附件》、ISO 2531。
- 规格范围：DN80–DN2000，壁厚等级 K9 / C 级。
- 材质：球墨铸铁 QT450-10，球化率 ≥ 80%（三级及以上）。
- 接口形式：T 型滑入式柔性接口、N1 型机械式接口，配三元乙丙（EPDM）橡胶圈。
- 内防腐：高炉水泥（普通硅酸盐水泥或硫铝酸盐水泥）离心衬里；外防腐：喷锌 + 沥青漆，喷锌量 ≥ 130 g/m²。
- 工作压力：DN80–DN300 允许工作压力 ≥ 4.0 MPa，DN350–DN600 ≥ 3.0 MPa。
- 环刚度/抗拉：管壁抗拉强度 ≥ 420 MPa，延伸率 ≥ 10%。

## 二、PE100 给水管
- 执行标准：GB/T 13663.2《给水用聚乙烯（PE）管道系统》。
- 原料：PE100 级聚乙烯专用料，混配料密度 ≥ 0.949 g/cm³。
- 规格：dn20–dn800，SDR11（PN16）/ SDR17（PN10）。
- 卫生性能：符合 GB/T 17219 生活饮用水输配水设备卫生安全评价要求。
- 静液压强度：20℃、100h 环应力 12.0 MPa 不破坏、不渗漏。
- 氧化诱导时间（200℃）≥ 20 min；纵向回缩率 ≤ 3%。

## 三、PE 燃气管
- 执行标准：GB 15558.1《燃气用埋地聚乙烯（PE）管道系统》。
- 规格：dn32–dn630，SDR11 / SDR17.6。
- 颜色：黑色加黄色色条或黄色，符合燃气标识要求。

## 四、配套管件与附件
- 法兰、三通、弯头、渐缩管、伸缩节等，与主管材同标准配套；
- 橡胶密封圈采用 EPDM，符合 GB/T 21873 要求，耐久性满足 50 年设计寿命。

所有产品出厂前 100% 经外观、尺寸、力学性能与水压试验检验，附质量合格证、材质报告与第三方型式检验报告。
