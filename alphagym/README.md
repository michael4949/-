# AlphaGym · 反事实基准引擎

> 回答一个所有交易复盘软件都回避的问题：
> **你上一轮赚的，是技能还是运气？**

传统复盘软件（如交易练习者 / TEx）给你回放和图表，但从不评估你。
胜率 54%、收益 +27% 这些数字看着很实在，可它们无法区分「你有优势」和「这段行情好」。
这个引擎补上的就是这一环。

```
交易记录 ──▶ 条件随机化检验 ──▶ 结构化事实 JSON ──▶ LLM 只负责翻译成人话
                    │
                    └─▶ p 值 / 百分位 / 四维归因 / 所需样本量
```

## 三个核心设计

### 1. 对照组必须复制你的交易习惯

天真做法是「让程序随机瞎做一堆交易比一比」。这是错的：
如果你做了 20 笔、平均持仓 30 根，而对照组做了 200 笔，
两者差异里混进了**交易频率和手续费**，根本不是判断力的差异。

正确做法是**条件随机化**：对照组复制你的笔数、持仓时长分布、多空比例、仓位分布，
只随机化被检验的那一个维度。你的真实交易恰好是该随机化分布中的一个样本点，
所以 p 值是**精确**的，不依赖任何正态性假设。

### 2. 决策归因不是另一个功能，它就是同一套检验的输出

逐维度各做一遍随机化，自然得到四项能力的独立评估：

| 零模型 | 保留 | 随机化 | 回答 |
|---|---|---|---|
| 行为匹配 | 笔数·时长·多空比·仓位分布 | 入场点 + 全部配对 | 一只有你习惯但没判断力的猴子能做到多少 |
| 入场时机 | 每笔的时长/方向/仓位及次序 | 入场点 | 你选的进场点比随机撞进去强吗 |
| 方向 | 持仓时段·仓位·多空数量配比 | 多空标签的分配 | 你把「做多」贴到了该贴的交易上吗 |
| 出场时机 | 入场点·方向·仓位·时长多重集 | 哪次持有多久 | 你选的离场点比随便平掉强吗 |
| 仓位 | 全部时点与方向 | 仓位的分配 | 你在更有把握的机会上下重手了吗 |

⚠️ 四项**不可相加**。各维度随机化互不正交，只能给相对排序，不能给可加分解。
详见 [`docs/CALIBRATION.md`](docs/CALIBRATION.md) 第 4 节的实测泄漏量。

### 3. LLM 只翻译，不判断

引擎输出结构化 JSON，大模型拿不到 K 线、拿不到逐笔记录，只拿到算好的数字。
**幻觉不是靠提示词恳求消除的，是靠信息隔离让它在物理上无从发生。**

副产品有两个：报告里每句话都能追溯到某个字段（可审计）；
输出结构上只包含对历史行为的描述性归因，不含价格预测和买卖建议（可合规）。

## 统计严谨性

这套东西的价值全部建立在「p 值是真的 p 值」之上，所以校准是第一等的事：

- ✅ 五个零模型的实测一类错误率**全部落在名义值的二项 95% 区间内**（n=1500，真实行情）
- ✅ 归因矩阵**四行全部命中对角线**——能正确指出技能所在维度
- ✅ 多重比较用 Holm–Bonferroni 校正（不校正的话，无技能用户约 19% 会拿到虚假的能力认证）
- ✅ p 值用 +1 修正，永不报告 p=0
- ✅ 后见之明上界的 O(K·n) 动态规划与暴力枚举逐一对拍
- ✅ 同 seed 逐字节可复现——成绩可审计、可申诉

**开发过程中，校准测试抓出了三个真实缺陷**，包括一个让「仓位管理」整个维度
在数学上不可观测的定义错误。三个缺陷都不会让产品变难看，只会让用户更高兴——
所以只可能被统计检验抓住，永远不会被「跑一下看看效果」抓住。
全部记录在 [`docs/CALIBRATION.md`](docs/CALIBRATION.md) 第 3 节。

## 目录

```
src/
  engine.js       对外入口：analyzeSession() → 结构化报告
  nulls.js        五个条件随机化零模型  ← 理论核心
  benchmarks.js   参照基准（含 O(K·n) 完美后见之明动态规划）
  trades.js       结算所：用户与对照组走完全相同的成本模型
  behavior.js     行为偏差检测器（确定性计算，无模型推测）
  stats.js        p 值 / PSR / Holm 校正 / 样本量
  rng.js          确定性随机源（严格均匀的 stars-and-bars）
  bars.js         K 线与 ATR / 行情状态标注
  report.js       文本渲染 + LLM 契约与系统提示
  simulate.js     合成交易者（校准与归因验证用）
test/             30 项，含统计校准与暴力对拍
tools/            深度校准 / 归因矩阵 / 数据导出
docs/CALIBRATION.md   校准报告（含已知局限）
```

## 数据

`data/` 下是**真实历史行情**（GOOG 日线 2148 根，含 2008 金融危机；EURUSD 小时线 5000 根），
来自 backtesting.py 的公开测试夹具。用真实数据而非随机游走是刻意的：
跳空、波动率聚集和肥尾正是最容易让随机化检验失效的地方。

A 股 / 期货数据管道见 `tools/`（下一阶段）。

## 局限

见 [`docs/CALIBRATION.md`](docs/CALIBRATION.md) 第 6 节。摘要：
维度间存在结构性泄漏；结论仅针对单段行情；重叠持仓会削弱可比性；
结论对成本假设敏感。这些都写进了每一份报告的 `caveats` 字段，强制向用户披露。
