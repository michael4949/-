# 新版 demo

一个**自包含单文件** HTML（542 KB），双击即开，无需服务器、无需联网。

```bash
node webdemo/build.js     # 生成 dist/alphagym-demo.html
node webdemo/smoke.js     # 用 Chromium 真的点一遍并截图（24 项断言）
```

## 里面哪些是真的

| 能力 | 上一版原型 | 现在 |
|---|---|---|
| K 线数据 | `mulberry32` 随机游走 | 真实历史行情（GOOG 日线 2148 根含 2008 崩盘 + EURUSD 小时线） |
| 下单 | `onclick="toast('已模拟下单')"` | 真撮合引擎，持仓与权益实时变动 |
| 双盲判定 | `Math.random()>0.45`，与图表和你的选择都无关 | 真实后续 20 根涨跌幅 |
| AI 复盘 | 3 条硬编码字符串 | 5 个条件随机化零模型 × 2000 次蒙特卡洛 |
| 智能问数 | 3 条硬编码结果，不匹配一律返回「股灾」 | **已移除** —— 没做出来就不放 |
| 相似行情 | 6 段假 K 线，「93% 匹配度」是写死的字符串 | **已移除** —— 没做出来就不放 |
| 用户评价 | 编造的三条推荐语 | **已移除** |
| 防未来数据 | 全量数据在前端，游标只管显示 | `GuardedBarSource`，越界读取抛异常 |

页面里跑的引擎和 Node 端跑 50 项测试、跑 1500 次统计校准的是**同一份源码**，
`build.js` 只是去掉 `import`/`export` 把模块拼进同一个作用域，没有为演示改过一行逻辑。

## 唯一的妥协

静态单文件意味着行情数据必须随文件下发，打开控制台能翻到后续 K 线。
`GuardedBarSource` 已把越界读取做成抛异常，但在纯前端环境里这道闸只能挡住代码，挡不住人。

**生产环境中 GuardedBarSource 必须部署在服务端**，客户端只拿已揭晓的分片，撮合也在服务端权威判定。
页面「这是什么」一栏对用户明写了这一点。

## 开发中被浏览器测试抓出来的两个真 bug

1. **报告渲染进了不可见容器**：`runReport` 先切 hash，`hashchange` 触发的 `route()` 此时
   `S.report` 仍为 null，于是又把 `#repBody` 重新隐藏。`textContent` 读得到、肉眼什么都看不见。
2. **双盲漏了时间轴**：只缩放价格没有平移时间戳，品种名打了码，X 轴却明明白白写着 `2005-03`，
   看一眼坐标轴就能反查是哪段行情。已在引擎层修复（整数天平移，保持日界与时间顺序），
   并补了回归测试。
