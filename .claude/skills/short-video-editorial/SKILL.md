# 短视频选题与内容策划（神 > 形）

做短视频最容易犯的错：先搭好模板（顶部标题、鼠标动效、字幕、配乐），再往里塞内容。
结果"形似神不似"——壳子很像爆款，但观众 3 秒划走，因为**没有值得看的内容**。

这个 skill 的唯一目的：**在做视频之前，先把内容想透。**
先回答"这条内容凭什么占用观众几十秒、他为什么要看完、看完记住什么"，
**然后**才决定画面和配音。模板是用来承载内容的，不是用来替代内容的。

---

## 工作流（务必按顺序，不要跳到画面/模板）

### Step 1 · 通读 + 含金量评估
- **完整读原文**（不是只看摘要）。该 fetch 就 fetch，该看 README/文档/评论就看。
- 评估含金量，逐项打分（1-5）并给一句话理由：
  - **新**：是不是新东西/新做法？还是又一个 me-too？
  - **猛**：有没有硬核能力/突破？
  - **省 / 快 / 强**：有没有可量化的优势（速度、成本、准确率、star 数、价格）？
  - **独家 / 反常识**：有没有"我以为不可能"的点？
  - **可用**：观众看完能立刻用上 / 受益吗？
- 给出**选题判断**：一句话说清"这是什么级别的东西、解决了谁的什么痛点"。
- **诚实**：如果含金量不足（总分低），明说"这条偏弱"，并给出唯一最强的切入角度，
  或建议换素材。**绝不靠形容词和情绪硬吹空内容。**

### Step 2 · 提炼"金块"（gold nuggets）
- 挑 3-6 个**具体、可验证、有冲击力**的点。每个金块必须满足：
  - 具体到能写进一句话，且**带事实/数字/对比**。
  - ❌ "它非常强大" → ✅ "缓存命中率 99.82%，同样的调用别人花 61 美元，它几乎不要钱"
  - ❌ "很多人在用" → ✅ "上线 3 周冲到 7400 star"
- 来源必须是原文里的真实信息，**不许编数据**。拿不准的标注"原文未给具体数值"。
- 砍掉：正确的废话、空泛形容词、人尽皆知的背景。

### Step 3 · 观众与钩子
- **谁在看**：画出目标观众（如：想降本的独立开发者 / 关注 AI 工具的从业者）。
- **他要什么**：痛点或好奇心是什么？
- **前 3 秒钩子**：用最强的那个金块做钩子（反差 / 数字 / 利益 / 悬念），
  让人"必须看下去"。钩子 = 金块，不是空喊"太炸了"。

### Step 4 · 结构与取舍
- 黄金结构：**钩子 → 这是什么(一句讲清) → 为什么炸(逐个金块，一镜一个) → 能干嘛(场景/收益) → CTA**。
- 明确写出**讲什么 / 砍什么**。宁可少而精，不要面面俱到。
- 信息密度高、节奏快，但每一句都得"有料"。

### Step 5 · 画面计划（关键：把"形"接到"神"）
这是大多数自动化工具最敷衍的一步，也是最能拉开差距的一步。
**每个金块都要配一个能"佐证它"的具体画面，而不是随机动效。**
- 指明**截哪个页面 / 滚到哪一屏 / 框出哪块区域**。
- **鼠标要指 / 点的，就是当前正在讲的那个元素**：
  - 讲"7400 star" → 鼠标移到 star 数字并点一下；
  - 讲"缓存 99.82%" → 鼠标划过/圈出那行数据；
  - 讲"一行命令安装" → 鼠标选中那行命令。
- 画面服务于"我正在说的这句话"，让观众**眼睛看到的和耳朵听到的对上**。
  这是"真人讲解"和"PPT 念稿"的根本区别。
- 没有合适真实画面时，宁可用一张干净的关键信息卡，也不要塞无关空镜。

### Step 6 · 配音脚本
- **一句一个金块**，口语化、有节奏、像跟懂行的朋友安利。
- 用**事实和数字**说话，不堆形容词。删掉"非常/超级/震撼"这类空词，换成具体的事。
- 控制语速与字数（中文约 5.5 字/秒），每句短促有力。

## 反面清单（出现任何一条就重做）
- 空泛吹捧、模糊断言（"很强大""遥遥领先"却说不出具体强在哪）。
- 编造 / 夸大数据。拿不准就标"原文未给"。
- 为动效而动效：鼠标乱飘乱点、画面和正在讲的内容**对不上**。
- 面面俱到、平均用力，没有最猛的那个点打头。
- 先定模板再凑内容。**永远反过来：内容定了，再选怎么呈现。**

## 产出格式（对接本项目的视频管线）
分析完输出一份结构化「编导方案」，字段对应 app 里的 `VideoPlan` 与画面选择：

```
含金量评估：{新/猛/省/独家/可用 各打分 + 一句话理由} + 选题判断（值不值得做、最佳角度）
bannerTitle：顶部固定大钩子（10-22字，来自最强金块）
金块清单：[{ 点, 支撑数据/事实, 来源 }]
分镜脚本：[
  { role: hook/body/cta,
    narration: 这一镜配音（一句一个金块，含具体数字）,
    caption: 屏幕大字（更短更爆）,
    visual: 画面（截哪页/滚到哪/框哪块）,
    cursor: 鼠标指/点的具体元素（要和 narration 对上）}
]
douyinCaption + hashtags
```

本项目里：先用 `extractContent` 拿到 `SourceMaterial`，
按本方法把它升级成「编导方案」，**再**喂给脚本/画面/渲染。
顺序永远是：**含金量 → 金块 → 画面+配音 → 才渲染。**
