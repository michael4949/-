ARCHITECTURE · 智能体解剖

一个中枢大脑，五层智能协同

智能体 = 感知 + 认知 + 决策 + 交互 + 执行的闭环组织，所有层共享同一个排程大脑与知识库。

L1感知层 · Sense

多源数据实时入流，事件总线替代微信群通知。

订单 / 做市商系统原料·在途·模具库存设备 IoT 状态✨ 数据质量哨兵

L2认知层 · Model

构建工厂数字孪生：资源、工艺、约束、换型损耗。

物料-产线-模具绑定换型时间矩阵工艺路径 / BOM✨ 换型自学习

L3决策层 · Decide

齐套引擎 + 9 类排程算法 + 多目标寻优求解。

预处理→计算→优化快速插单 ×3 模式✨ What-if 沙盘✨ 可解释报告

排程大脑 · Scheduling Brain

大语言模型负责理解与解释，运筹求解器负责计算与寻优，规则引擎承载排程员的专家经验 —— 三引擎共脑，人审后发布。

🧠 LLM 推理与对话⚙️ OR 求解器📚 专家规则知识库🔁 实绩反馈学习

L4交互层 · Collaborate

甘特协同 + 自然语言 Copilot，排程员始终掌握终审权。

拖拽调整 / 一键调度冲突实时检测✨ 对话式排程✨ 移动审批

L5执行层 · Act

工单下发到机台，验收回执实时回流，状态全程可追。

电子作业指导书下发履历达成统计 / 异常预警✨ 预测性预警

L∞学习环 · Learn

每一次人工调整都是一次训练：经验进库、参数自校准。

换型/节拍回归校准✨ 调整意图学习✨ KPI 自动周报
