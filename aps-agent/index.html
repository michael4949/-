给现有生产系统，
装上一颗「智能排产大脑」

江铜现有生产系统已经管住了订单、库存、工艺、下发、监控、报表六类业务数据——但「排产」这个决策环节， 仍依赖排程员手动整理 Excel、逐一查库存、微信群通知产线。 本方案不推翻、不重建：以 AI 智能体挂接现有系统，把人工经验决策升级为 小时级智能排产 + 人审发布 + 事件闭环。

ROADMAP · 嵌入式落地

三步走，嵌入现有系统

与调研规划一致：先打通数据源，再上线智能排产，最后闭环学习——每一步都在现有系统之上叠加，不影响在产业务。

P1
打通数据源第 1–4 周 · 利旧接口
  • 对接订单系统：订单数量、交付期限实时入流
  • 对接库存数据：原料 / 在途 / 模具 / 在制品
  • 梳理器件型号 × 设备型号绑定关系
  • 数字化换模损耗时间矩阵（实测校准）
  • 数据质量哨兵上线，杜绝脏数据排程
P2
智能排产上线第 5–10 周 · 并行试运行
  • 小时级排产引擎：多目标寻优 + 约束求解
  • 急单插单与设备故障应急重排方案
  • 甘特可视 + 拖拽微调 + 冲突检测
  • 排程员审核后一键发布（替代微信群）
  • 与手工排程并行对比 2 周，验证后切换
P3
闭环与学习第 11 周起 · 持续运营
  • 下游产线自动下发通知 + 电子验收回执
  • 订单状态实时跟进，实绩自动回流
  • 偏差超阈值自动滚动重排
  • 专家经验持续入库，参数自学习校准
  • 排产 Copilot 全员开放，KPI 自动周报
