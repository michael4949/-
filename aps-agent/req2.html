ROADMAP · 嵌入式落地

三步走，叠加在做市商系统与 Oracle ERP 之上

P1
打通数据与规则第 1–4 周 · 利旧接口
  • 对接做市商系统：订单 / 工单 / 铜锡行情
  • 对接 Oracle ERP 财务科目与凭证接口
  • 导入报价表与报价规则（客户待提供）
  • 梳理模具台账、辅料（拉丝油/镀锡液/镍铜）台账
  • WMS 库存（可用 / 冻结）实时入流
P2
AI 应用 + 智能排产上线第 5–10 周 · 并行试运行
  • 报价测算（PC + 移动端）与订单评审智能体
  • 销售订单自动生成 + 电子工艺卡智能推荐
  • 辅料测算与请购联动
  • 多目标智能排产 + 增量重排 + 排产模拟
  • 甘特可视化 · 拖拽调整 · 冲突提示
P3
锁库防错 + 成本闭环第 11 周起 · 持续运营
  • 按工单锁库 · 释放规则 · 冲突按优先级
  • 领料防错报警，后工序零领错
  • 延期 / 物料 / 产能预警推送企微钉钉
  • 工单级成本归集，自动推送 Oracle ERP 凭证
  • 废品率 · 一次合格率自动采集，成本反哺报价
