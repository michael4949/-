# ZenFlux AIOS · 产品官网（浅色 AI 主题）

参考 `zenflux.cn/zenfluxaios` 的产品形态重新设计的 **AIOS（企业 AI 操作系统）官网**：
全新浅色配色（冷白底 + 靛蓝→紫罗兰→青色极光渐变），零依赖纯静态，双击即可打开。

## 预览

```bash
# 方式一：直接用浏览器打开
open aios/index.html

# 方式二：本地起个静态服务
cd aios && python3 -m http.server 8080   # http://localhost:8080
```

## 设计系统

- **基底**：`#F7F9FF` 冷调浅白，白色卡片 + 发丝级描边 + 柔和投影
- **主渐变**：`#5A5BF0 → #9A4DFF → #00C2D8`（靛蓝 → 紫罗兰 → 青）
- **AI 氛围**：固定极光光斑背景、点阵网格、Hero 神经网络粒子 Canvas、
  流光工作流连线（SMIL `animateMotion`）、玻璃拟态导航与控制台
- **动效**：滚动浮现（IntersectionObserver）、数字滚动、打字机循环；
  完整支持 `prefers-reduced-motion` 降级；粒子画布离开视口自动暂停
