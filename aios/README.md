# 顶呱呱AI操作系统 · 企业AI智能工作台

复刻 `zenflux.cn/zenfluxaios` 工作台界面的**单文件应用原型**（品牌更名为「顶呱呱AI操作系统」），
浅色 AI 配色（冷白底 + 靛蓝→紫罗兰→青色渐变），零依赖，双击 `index.html` 即可打开。

## 交互细节

- 待办：勾选完成（划线 + 移入「已完成」）、删除、`＋` 新增（回车提交）、红点优先级、来源彩色标签
- 对话：回车发送、模拟打字指示器与轮换回复、「继续追问」追加对话、👍👎 可点
- 调度卡条目点击直接跳转对应智能体页面（与原站「点击条目可直接跳转」一致）
- 顶栏：专注模式（折叠侧边栏）、右侧面板收起/展开；移动端侧边栏与面板均为抽屉式
- 问候语按当前时间动态生成（早上好/下午好… + 当日日期星期）
- 全局 Toast 反馈、协议说明弹窗（Esc/遮罩关闭）、`prefers-reduced-motion` 降级

## 配色

浅色底 `#F6F8FE` + 白色卡片，主渐变 `#5A5BF0 → #9A4DFF → #00C2D8`，
极光光斑 + 点阵背景营造 AI 氛围；待办来源标签按类型着色（日历蓝/邮件绿/搭子紫/云端青/成长橙）。
