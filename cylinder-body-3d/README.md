# 气缸体 3D 模型 / Cylinder body — drawing S1-2505

由二维铸造/加工工程图纸（`气缸体`, 图号 **S1‑2505**, 材料 **ZG08Cr19Ni9**, 比例 1:5,
共 2 张）反求出的**三维实体模型**。

> ⚠️ 这是**还原/示意模型 (representative model)**：外形包络、主要孔系、法兰、螺栓圈、
> 进排气口等均按图纸读取的尺寸建立；但内部铸造水腔/气腔型芯、精确公差 (H7/F9 等)
> 与未注铸造细节做了简化。用于可视化、评审、装配占位与询价沟通，**不可直接用于最终加工**。

## 这是什么

一台**八角形铸造气缸体**（推测为多缸径向/方形布置的压缩机或泵体，带水冷腔）。
主要特征：

| 特征 | 尺寸 (mm) | 来源 |
|------|-----------|------|
| 总长（主轴向 X） | 900 | B‑B / C‑C 剖视 |
| 八角截面对边 (Y, Z) | 765 | 主视图 / B‑B |
| 中央主孔（曲轴/主轴承孔） | Φ490 H7，通孔 | B‑B |
| 端面轴承止口 | Φ520，深 ~38 | B‑B |
| 中央法兰螺栓圈 | Φ590，24×孔 | 主视图 |
| 4 个气缸法兰（每端面，45°角） | 孔 Φ130，8×螺栓 | 主视图 / A‑A |
| 顶部进气法兰 (+Z, 总进气) | Φ370，16×螺栓 | 主视图 |
| 底部排气法兰 (−Z, 总排气) | — | 主视图 |
| 左右侧口 (±Y) | 8×螺栓 | 主视图 |
| 未注铸造圆角 | R10~15 | 技术要求 |
| 水压试验 | 0.6 MPa / 30 min 不渗漏 | 技术要求 |

包络尺寸约 **900 × 825 × 827 mm**，模型体积 ≈ 0.247 m³（watertight 单一实体）。

## 文件

| 文件 | 用途 |
|------|------|
| `cylinder_body.step` | **CAD 通用格式**（B‑rep 实体）。可在 SolidWorks / UG NX / CATIA / Creo / FreeCAD 中打开、编辑、出图、做有限元。 |
| `cylinder_body.stl`  | 网格格式。3D 打印、快速查看、网格分析。 |
| `cylinder_body.glb`  | Web / AR 格式。用于网页与 `viewer.html`。 |
| `viewer.html`        | **交互式 3D 浏览器查看器**（可旋转/缩放）。直接双击在浏览器打开。 |
| `views/*.png`        | 各视角渲染图（等轴测、端面、顶面、对比图）。 |
| `build_model.py`     | 参数化建模脚本（CadQuery）。改尺寸→重生成。 |
| `render_views.py`    | 纯 numpy 软件渲染脚本（无需显卡/显示器）。 |

## 重新生成

```bash
pip install cadquery numpy trimesh pillow
python build_model.py     # -> cylinder_body.step / .stl
python render_views.py    # -> views/*.png
```

所有几何尺寸集中在 `build_model.py` 顶部的参数区，按需修改即可重建。

## 坐标约定

- **X** = 主孔轴向（总长 900），两端为八角形端面。
- **Y, Z** = 八角形截面所在平面，对边 765。
- 原点在零件几何中心。
