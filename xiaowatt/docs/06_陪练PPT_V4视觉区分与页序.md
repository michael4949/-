# 陪练 PPT V4 生图 · 与班组长 PPT 的视觉区分 + 页序

班组长 PPT 是"大场景实景照片 + 工程图纸线稿，左右分栏斜向溶解，深蓝铜金"。陪练 PPT 前两版（墨绿换色版、沙盘舞台版）都被用户否决：前者骨架相同，后者"多几页就单调"（每页上浅下深 + 一排米绿卡，只有墨绿金两色）。现行方案：

**「安全色 · 编辑式拼贴」**

| 维度 | 班组长（已生成） | 陪练（现行） |
|---|---|---|
| 画面语言 | 实景照片斜向溶解成蓝图线稿 | 大色块（丝网印刷颗粒、半调网点、轻微套印错位）+ 全彩实拍人物 / 设备抠图跨在色块边上 + 白色极细技术标注线（只有空心圆和短横线，不写字） |
| 配色 | 深蓝 #00367A / 铜金 / 琥珀橙，傍晚暖光 | 国标安全色：安全红 #D7262C（事故 / 禁止）、安全蓝 #1B5EAB（规程 / 系统）、安全黄 #F2B61B（警示 / 训练中）、安全绿 #1E8E5A（合格 / 能力）、应急橙 #F26B1D（应急）+ 墨黑 #1C1C1C、白、浅暖灰纸底 #F2F1EC。每页至少三种彩色，一种主色占六成，相邻页主色不同 |
| 版式 | 顶部米白标题带 + 左右分栏，页页同构 | 五种母版轮换：A 斜切分区 / B 圆窗（禁止标志的圆装照片）/ C 楔形放射（警告三角，步骤路径）/ D 指令牌网格（表格多项）/ E 全幅实拍 + 色带（封面目录结尾） |
| 标题 | 米白带内左对齐，导语药丸 | 主色色块内白字 Heavy 黑体，色块下压一条黄黑斜纹细带；英文墨黑小字 |
| 文字载体 | 开关柜门板、工作票、班组看板 | 指令牌方块、白色票据卡、色块内直排、警示带分隔 |
| 实拍 | 户外城市与配网，清晨傍晚 | 变电运行与培训场景（GIS 室、开关室、主控室、班前会、培训教室、实训基地、应急演练），冷白光；背景照片可按主色做双色调，前景主体全彩 |
| 母题 | 电杆、横担、绝缘子、环网柜、抢修车 | 安全帽、绝缘手套、验电笔、操作票夹板、安全围栏、黄黑 / 红白警示带、禁止圆与指令方 |
| 场景单位 | 光明供电局配网资产部 | 福田供电局变电运行班组 |

33 页轮换表（版式 · 主色 · 实拍）见会话中给用户的表；原则：相邻页版式与主色都不同，截图 / 架构图页仍带【参考图】段按原图比例留屏。

不变的：16:9 2560×1440；四周无框线十字；右上 12%×10% 留 logo；底部 4% 留页码；文字逐字准确；无模块编码、无页脚三件套；不用齿轮 / 管道 / 铆钉 / 压力表 / 核工业元素，不用盾牌 / 锁 / 警示三角等通用图标；不要卡通感、塑料感、霓虹。
