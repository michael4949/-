# 陪练 PPT V4 生图 · 与班组长 PPT 的视觉区分 + 页序

班组长 PPT 是"大场景实景照片 + 工程图纸线稿，左右分栏斜向溶解"。陪练 PPT 不沿用这套，整体换成另一种画面语言：

**"实训沙盘微缩摄影 + 金色全息训练层，居中舞台式构图"**

| 维度 | 班组长（已生成） | 陪练（本轮） |
|---|---|---|
| 画面语言 | 真实大场景摄影 + 深蓝蓝图线稿，虚实对半 | 实体沙盘模型的移轴微缩摄影（真实材质、真实景深）+ 悬浮的半透明金色全息薄片（雷达、题卡、操作票），实在下、虚在上 |
| 构图 | 左右分栏，照片斜向溶解成线稿 | 居中舞台式：上 60% 浅米绿背景，下 40% 墨绿哑光台面，沙盘居中，内容卡环绕或左右对称分列 |
| 标题 | 顶部 15% 米白带，左对齐 | 顶部居中，英文与导语条居中，导语条金描边药丸 |
| 底 | 米白图纸底 + 细网格 | 浅米绿 #F3F5F0 柔和渐变 + 极淡等高线纹；台面墨绿 #1F5C4A 带金色细刻线 |
| 主色 / 暖色 | 深蓝 #00367A / 铜金 #B8862B、琥珀橙 #E08A2E | 墨绿 #1F5C4A / 金 #C9A227、安全橙 #E8641B |
| 点缀 | 紫罗兰、墨绿、暖红 | 荧光黄 #F2C14E（反光条、围栏）、信号红 #C0392B（标示牌边、事故，极少）、石墨灰 #5A6670（设备、应用前） |
| 科技光 | 青蓝 #4FA3FF 数据光 | 金色 #E3B341 全息光（薄片描边与连线） |
| 面板 | 开关柜门板、工作票、班组看板 | 浅米绿圆角训练卡（金描边、轻微悬浮投影落在台面上）、全息薄片、空白标示牌 |
| 连接件 | 母线 + 断路器方框、带垂度导线 + 绝缘子 | 金色细光线（沙盘位置 → 卡片）、台面等高线刻纹、成熟度四级台阶（沙盘上的实体台阶） |
| 序号 / 指示 | 圆形指示灯、段落色圆徽 | 墨绿圆徽金描边；安全帽色点（白 / 蓝 / 红 / 黄） |
| 大数字 | 圆形电表盘 | 雷达图 / 半环仪表（demo 同款） |
| 母题 | 电杆、横担、绝缘子、环网柜、抢修车、铁塔、深圳天际线 | 微缩变电站（主变、门型架、隔离开关、GIS 室、开关室、主控室）、微缩培训教室截面与数字人大屏、微缩人物（深蓝工装、反光条、安全帽、橙色绝缘手套、验电笔）、安全围栏、空白标示牌、操作票 |
| 光线 | 清晨 / 傍晚暖光，户外 | 摄影棚柔和顶光，冷白为主，全息层金色 |
| 场景单位 | 光明供电局配网资产部 | 福田供电局变电运行班组 |

不变的：16:9 2560×1440；四周无框线十字；右上 12%×10% 留 logo；底部 4% 留页码；文字逐字准确；截图 / 架构图页带【参考图】段按原图比例留屏；无模块编码、无页脚三件套；不用齿轮 / 管道 / 铆钉 / 压力表 / 核工业元素；不要卡通感、塑料感、霓虹。
