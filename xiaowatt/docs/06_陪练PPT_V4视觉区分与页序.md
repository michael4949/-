# 陪练 PPT V4 生图 · 与班组长 PPT 的视觉区分 + 页序

用户三次否决后定下的原则：**画风不换**——保持用户喜欢的"超清晰、细腻、色彩鲜艳、丰富的半写实手绘"（202 厂参考海报那一路），**只在媒介、构图、配色、母题、布局上与班组长分开**。被否决的三版：墨绿换色版（骨架相同）、沙盘舞台版（多页后单调）、安全色编辑拼贴版（太丑）。

| 维度 | 班组长（已生成） | 陪练（现行） |
|---|---|---|
| 媒介 | 实景照片斜向溶解成深蓝蓝图线稿，"虚实结合" | **全画面半写实手绘插画**（厚涂数字绘画，超清晰、细腻、细节丰富），没有照片、没有线稿溶解；场景以**等轴测剖面**（变电站 GIS 室 / 开关室 / 主控室 / 培训教室 / 实训场 / 应急演练场的剖开截面）呈现 |
| 构图 | 左右分栏：一侧照片、一侧线稿与面板 | **上下结构或中心放射**：标题居中在上，宽幅剖面场景横贯画面；内容页为"中心剖面 + 四周面板"或"顶部横幅场景 + 下方面板"，不做左右分栏 |
| 配色 | 深蓝 #00367A 主 + 铜金 / 琥珀橙，米白图纸底 | **青绿为墨色、朱红为强调、明黄钴蓝橙草绿点缀，浅青灰底**：深青 #0E4F4F（标题、线条）、青绿 #0F7C7C（主色）、朱红 #D8322A、明黄 #F5C21B、钴蓝 #2457A8、橙 #F08A24、草绿 #4C9A3C、浅青灰底 #EAF2F0（极淡等高线纹，呼应 demo 背景）。每页五色以上，鲜艳饱满 |
| 科技光 | 青蓝数据光 | 青绿发光的"能力路径"（等高线状的光带，从作业现场流向教室大屏 / 雷达） |
| 面板 | 开关柜门板、工作票、班组看板 | 圆角训练卡 / 题卡（青绿描边、浅底）、黑板 / 白板、投影幕、数字人大屏、安全帽色圆徽（白 / 蓝 / 红 / 黄）做序号 |
| 连接件 | 母线 + 断路器、带垂度导线 + 绝缘子 | 等高线光带、接地线 / 验电笔做指引线、成熟度四级台阶 |
| 母题 | 电杆、横担、绝缘子、环网柜、抢修车、铁塔、深圳天际线 | 变电站剖面（主变、GIS 筒体、开关柜、控制屏）、培训教室剖面（课桌、数字人大屏、投影）、人物（深蓝工装、黄反光条、彩色安全帽、橙绝缘手套、验电笔、操作票夹板）、安全围栏、空白标示牌、灭火器 / 急救箱（应急页）、雷达图、台阶 |
| 光线 | 清晨 / 傍晚暖光 | 明亮白天、柔和体积光、鲜艳饱和 |
| 标题 | 米白带内左对齐 | **居中**，深青 Heavy 黑体；英文朱红小字字距加宽；导语条青绿细描边药丸，居中 |
| 场景单位 | 光明供电局配网资产部 | 福田供电局变电运行班组 |

不变的：16:9 2560×1440；四周无框线十字；右上 12%×10% 留 logo；底部 4% 留页码；文字逐字准确；截图 / 架构图页带【参考图】段按原图比例留屏；无模块编码、无页脚三件套；不用齿轮 / 管道 / 铆钉 / 压力表 / 核工业元素；不要卡通感、塑料感、霓虹。
