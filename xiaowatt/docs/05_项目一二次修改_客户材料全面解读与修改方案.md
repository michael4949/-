## 一、项目负责人转述的客户意见（原文逐句解读）

### 原文 1「核心重点」

> (1) demo必须更加偏向人力资源板块

解读：甲方是深圳供电局人力资源部。当前 demo 的主线是「变电倒闸操作训练工具」，人力资源的内容只在工作台、成长档案、班组看板里作陪衬。客户要求把主线反过来：以**岗位胜任能力评价**（认证表）为纲，考试是取证手段，能力雷达是评价结果，组长培训计划是培养动作，认证表签字是人力资源的出口。演示时先讲「人」，再讲「练」。

> (2) 之前做的陪练的场景，有点都是勾选 有点简单，而且有些视觉的场景不能用ai来做，在demo中体验不是很好。所以可以看哪些ai能接入，可以使用语音或者文字（填空，选择题（例如在图片中进行选择），问答题），等一些方式重新进行场景的渲染。

解读：现有陪练舱 29 项操作票的「点设备 / 长按 / 复诵输入」在客户眼里等于「勾选」，且「视觉动作识别」这类靠摄像头识别人动作的场景不能用 AI 真做（与反馈单第三节第 6 条、第五节第 4 条一致）。客户给出的替代题型是明确的五种：**语音**、**文字**、**填空**、**选择题（含在图片中点选）**、**问答题**。要求用这些题型把场景「重新渲染」，也就是每个考核点都换成一种 AI 能真实介入判定的题型，而不是在设备图上点一下。

### 原文 2「整个流程」

## 二、《AI智能陪练平台——项目负责人反馈单》全文与逐条解读

单位：福田供电局。联系人/负责人：于然。在线版本：小瓦特·练·AI智能陪练底座。建议定位：**保留体系，集中做深一个程序规则类样板**。

### 第一节 给项目组的总体反馈（原文）

> 领导认可AI陪练方向，但认为当前安全意识、倒闸操作、课程、成长档案、班组管理等范围过大，而且动作识别型陪练技术难度高。项目应形成"AI陪练体系+一个完整样板"，而不是铺开大量未完成的业务场景。
> 9063当前版本已经有明显进展：倒闸操作样板包含四个状态阶段和29项操作票内容，支持教学、演练、考核，具备错序、漏项、异常、红线、一票否决、评分复盘和专项重练。但18位教练中只有一位标记已开通，其余仍是规划；核心数据、AI结果和系统联动仍以单文件前端模拟为主。

解读：领导肯定方向、否定铺面。「9063」应为版本号或页面编号，指当前在线版本。29 项票、三模式、错序/漏项/异常/红线/一票否决/复盘/重练被承认为已完成；被否的是 17 个未开通教练与「前端模拟」的 AI 结果。

### 第二节 领导反馈及必须整改事项（表格原文）

| 领导关注点 | 当前情况 | 下一次汇报前必须处理 | 验收方式 |
|---|---|---|---|
| 陪练必须允许做错 | 当前版本已出现错误和红线逻辑 | 现场真实演示错序、漏项、红线三类错误，并提供不同反馈 | 三类错误均显示步骤、风险、依据和纠正动作 |
| 能力维度需专业确认 | "唱票复诵"等过程项是否作为能力维度仍存疑 | 请安全专家审定能力维度、29项顺序、红线、权重和条款 | 形成有版本、姓名、日期的确认记录 |
| 与南网自学/人资域交叉 | 课堂、档案、班组端容易被理解为重复建设 | 明确现有平台负责课程、题库、考试、人员主数据；本产品负责情境练习、过程纠错、复训与回写 | 一页边界表讲清输入输出 |
| 范围太大、做不完 | 18位教练中仅1位真正开通 | 本轮只承诺倒闸操作样板，其余归入陪练地图或二期 | 不把未开通卡片介绍为已完成场景 |

逐行解读：
1. 三类错误（错序 / 漏项 / 红线）要能现场触发，每类反馈都要含「步骤、风险、依据、纠正动作」四要素。新的 1163 关卡里对应：漏项＝只看就地控制柜不看机构箱和连杆；错序＝未验电先合地刀；红线＝跳过验电直接接地（一票否决）。
2. 能力维度要由安全专家审定并留「版本、姓名、日期」的确认记录。新雷达维度要挂一条确认记录（演示用虚拟专家姓名，标注「由人确认」）。
3. 边界：现有平台管课程、题库、考试、人员主数据；本产品管情境练习、过程纠错、复训、回写。要出一页「边界表」（输入 / 输出）。注意：这里说「题库、考试」归现有平台，而客户新口径要我们做「题库考试」——理解为：**题目内容由现有平台/专家供给，本产品做情境化的考试执行与过程纠错**，边界表上照此写。
4. 只承诺倒闸操作样板；其他归入「陪练地图」或二期；未开通教练不能说成已完成。
5. 倒闸＝程序规则类样板；客服＝语言类样板；视觉动作类后置。要能解释四类陪练及成熟度。
6. 训练→复盘→任务回写要可保存、刷新可回看，且评分复盘、成长记录、班组任务三处状态一致。

### 第三节 当前在线版本不能按"已完成"汇报的内容（原文）

> 1. 其余17位教练只是目录或规划，不是可训练功能。

> 5. 知识课堂课程、题库、画像同步和学时回写目前未证明已完成真实接口联调。
> 6. 图片/视频动作识别尚无可靠证据，本阶段不得作为已实现能力。

解读：这六条是「口径红线」。原型里凡属这六类的功能，界面照常可用，但讲师演示台的「功能实现状态清单」必须标为 规则模拟 / 预置 / 待对接，讲稿不得说成已实现。

## 三、《#3主变雨淋阀水喷雾系统机械手动启动实操培训方案》全文解读

（文件名：3号主变雨淋阀机械手动启动_交互培训方案_雨淋阀检查版.md）

**1 项目定位 / 1.1 培训场景「实操2」**：#3主变防护区发生火灾，且消防报警主机故障、无法远程启动。员工需现场完成七步：① 找到 #3主变雨淋阀；② 检查阀组状态（管网/供水侧压力表正常、隔膜/控制腔压力表正常、进水蝶阀开启、出水蝶阀开启）；③ 找到 #3主变雨淋阀紧急启动阀盒；④ 开盖，将盒内手动阀操作至全开，机械手动启动；⑤ 确认水喷雾正常喷水；⑥ 前往消防水泵房检查大泵；⑦ 大泵未自启则在控制柜切手动并确认两台泵运行。

**2 素材选型说明**：不建议再把设备统称「蝶阀式雨淋阀」。按考核标准里的「隔膜压力表 / 控制腔压力表」「紧急启动阀泄压启动」特征，画面应按**隔膜式雨淋报警阀组 + 阀组前后进/出水蝶阀**制作：阀本体用隔膜式阀组素材；进水蝶阀、出水蝶阀作为阀组前后的控制阀单独设置；不要把普通「消防信号蝶阀」误认为阀本体。最终上线前以本单位 #3主变现场照片、铭牌、规程替换网上占位素材。

**3 培训形式**：交互式图片 + 热区点击 + 拖动/旋转模拟操作 + 条件分支；16:9 横屏。**3.1 交互原则**：检查类＝点击部件；阀门操作类＝拖动或旋转，不是单击完成；控制柜类＝点击真实位置上的转换开关、按钮；默认不给正确热区，错够次数才弱提示；所有错误记录但不退出；危险/明显错误设为「关键错误」，立即弹原因并回到当前步；用模拟画面，不在真实带压带电设备上试操作。

**4 关卡总体流程**：两阶段——阶段一 雨淋阀正常状态检查 → 确认处于正常备用 → 阶段二 #3主变火灾、报警主机故障 → 找到 #3主变雨淋阀 → 打开紧急启动阀盒 → 手动阀全开 → 确认水喷雾正常 → 结束结算。**设计原则**：检查环节只查阀组本身；不设水泵房检查；不在本关安排控制柜操作；火情后不重复完整检查；检查内容以现场实际阀组为准，重点是压力表和进出水阀门状态。

**5 场景详细设计**
- **场景0 正常状态检查**：画面用阀组完整正面/斜正面图，至少体现：管网/供水侧压力表、隔膜/控制腔压力表、最上方出水阀门、进水阀门、雨淋阀本体、紧急启动阀盒。检查四项：管网压力、隔膜压力、出水阀门开启、进水阀门开启。交互：依次点击部件。压力表点击后放大表盘：正常「压力正常。」异常「压力异常，请确认雨淋阀组是否具备正常投入条件。」出水阀门点击显示阀位：正常「出水阀门处于正常开启位置。」否则「出水阀门状态异常。」进水阀门同理「进水阀门处于正常开启位置。」/「进水阀门状态异常。」通过条件：四项全部正常，提示「#3主变雨淋阀组处于正常备用状态。」随后进入火情场景。
- **场景A 火情后正确找到 #3主变雨淋阀**：「主变雨淋阀区域」全景交互图，至少出现 #1、#2、#3、#4 主变雨淋阀（或其他相似消防设备），每套附现场式编号牌。任务：点击 #3主变雨淋阀。正确「已确认 #3主变雨淋阀，请检查阀组状态。」错误「该设备不是 #3主变雨淋阀，请重新确认设备编号。」重点：紧急情况下设备对象不选错。
- **6 场景B 火情后的快速确认**：不重做完整巡视，只快速确认编号无误、外观无明显异常、前置检查已确认备用；随后立即进入紧急启动。「本场景不重复要求逐项检查压力表和阀位，避免降低应急处置速度。」
- **7 场景C 机械手动启动**（最核心）。7.1 找紧急启动阀盒：继续用阀组完整图；正确热区＝紧急启动阀盒，干扰热区＝电磁阀、试验阀、排水阀、其他小阀；任务提示「消防报警主机故障，请在 #3雨淋阀本体处实施机械手动启动。」7.2 开盖：点对后播放开盖动画（关闭 → 打开可见手柄）。7.3 手动阀全开：不做「点一下按钮」；拖动手柄 关闭 → 中间 → 全开，只有到全开区域才判成功。正确「#3雨淋阀手动应急阀已全开，雨淋阀系统启动。」错误：未到全开「手动阀未完全开启，请继续操作至全开位置。」点其他阀「该阀门不是雨淋阀紧急启动阀。」关键错误：操作错误雨淋阀、操作主排水阀、操作与紧急启动无关的主要控制阀——进考核记录。
- **8 场景D 确认水喷雾**：切到 #3主变场景，动画显示主变本体、周边喷头、多方向覆盖。学员先点水喷雾区域检查，再显示「#3主变水喷雾系统喷水正常。」，「确认水喷雾正常」按钮不能立即出现。异常扩展（无喷水 / 部分无水 / 压力不足）首版不加。

**9 火情阶段结束条件**（八项）：#3主变雨淋阀＝已正确识别；管网压力＝已检查正常；隔膜压力＝已检查正常；进水蝶阀＝正常开启；出水蝶阀＝正常开启；紧急启动阀盒＝已打开；手动启动阀＝已全开；#3主变水喷雾＝已确认正常。完成提示「#3主变雨淋阀水喷雾系统机械手动启动处置完成。」水泵控制柜手动启泵建议独立项目。

## 四、《110kV 培训三线 1163 线路陪练关卡方案（开关检查 + 地刀检查修订版）》全文解读

**一 关卡设计目标**：基于「将 110kV 培训三线 1163 线路由运行转检修」操作票简化，不完整复现整票，只保留两个能力：① 断开开关后的状态检查；② 验电、接地及接地后的状态检查。第一关训练「操作完成后必须检查实际状态」，第二关训练「确认无电后才能接地，并在接地后确认地刀实际合闸到位」。

**二 关卡一 断开开关后的状态检查**。2.1 目标：1163 分闸后不能直接进下一步，须确认 ① 后台/监控画面显示分闸位置；② 现场机构箱内部分、合闸指示为分闸；③ 三相无电流。核心意识「**执行了分闸操作，不等于已经确认分闸成功。**」2.2 流程：断开 1163 → 检查后台分闸 → 现场机构箱指示 → 三相无电流 → 综合确认可靠分闸。2.3 交互：检查清单三项「[ ] 后台显示 1163 开关在分闸位置 / [ ] 现场机构箱内部显示分闸 / [ ] A/B/C 三相无电流」，全部确认后通过。

**三 关卡二 验电、接地及接地后的状态检查**。3.1 目标：停电隔离完成后，先确认无电，再合 116340 地刀；地刀操作完成后不能以「命令已执行」为完成依据，要检查实际合闸到位。核心意识「**验明无电后才能接地；地刀操作后还必须确认实际位置。**」3.2 验电两项：检查 1 后台线路二次电压——「培训三线 1163 线路二次确无电压。」检查 2 高压带电显示装置——「1163 间隔高压带电显示装置显示确无电压。」两项均完成才能接地。

**四 116340 地刀合闸**：确认无电后允许「合上培训三线线路侧 116340 地刀。」合闸后立即进入「地刀状态确认」。

**五 合上后的状态检查**。5.1 三个位置：① 就地控制柜——「116340 地刀在就地控制柜上的位置指示是否为合闸状态。」② 刀闸机构箱分、合闸指示——「机构箱上的分、合闸指示显示 116340 地刀已合闸。」用于确认现场机械位置，不能只靠控制柜电气指示。③ 刀闸连杆位置——「刀闸连杆位置是否与 116340 地刀合闸状态相符。」确认机械传动已实际到位。5.2 逻辑：合地刀 → 控制柜指示 → 机构箱指示 → 连杆位置 → 三项一致 → 确认到位。5.3 推荐交互「**一张现场全景图 + 三个可点击检查点 + 局部放大图**」，清单「[ ] 就地控制柜显示合闸 / [ ] 刀闸机构箱分、合闸指示显示合闸 / [ ] 刀闸连杆位置符合合闸状态」，三项全完成才判「116340 地刀已可靠合闸。」

**六 错误反馈四种**：情况一 只看就地控制柜——「检查不完整。就地控制柜已显示合闸，还需要检查机构箱分、合闸指示和刀闸连杆位置。」情况二 控制柜与机构箱不一致——「状态不一致。就地控制柜指示与现场机构箱机械位置不一致，当前不能确认地刀已经可靠合闸。」情况三 机构箱合闸但连杆异常——「机械状态确认异常。请检查刀闸连杆位置，确认机械传动机构是否已经实际到位。」情况四 全对——「116340 地刀状态检查完成，已确认地刀合闸到位。」

**七 最终整体流程**：进入陪练 → 任务「将 110kV 培训三线 1163 线路由运行转检修」→ 关卡一（断开 1163 → 后台分闸 → 机构箱指示 → 三相无电流 → 确认可靠分闸）→ **系统完成中间非重点步骤** → 关卡二（后台二次无电压 → 带电显示装置无电压 → 合 116340 → 控制柜指示 → 机构箱指示 → 连杆位置 → 确认可靠合闸）→ 关卡完成。

**八 图片素材建议**：第一关 ① 1163 后台状态画面；② 机构箱内部图片；③ A/B/C 三相电流画面。第二关 ① 后台电压画面；② 高压带电显示装置；③ 116340 就地控制柜位置指示；④ 机构箱分合闸指示；⑤ 连杆位置。地刀状态至少准备 正常合闸 / 异常未到位 两态，后续随机呈现让学员真判断。

**九 最终定义**：能力一「断开 1163 开关后，通过后台分闸状态、现场机构箱分合闸指示和三相电流，综合确认开关可靠分闸。」能力二「确认线路确无电压后合上 116340 地刀，并通过就地控制柜、刀闸机构箱分合闸指示和刀闸连杆位置，综合确认地刀可靠合闸。」两个习惯：「操作完成后，必须确认设备实际状态。」「验明无电后才能接地，接地后仍要检查地刀是否真正合闸到位。」

注意：本方案**没有给评分表**，也没有写「一票否决」，但反馈单第六节的演示主线（跳过验电直接接地 → 一票否决）落在本方案关卡二上。评分表由我方拟（第七节），须专家确认。

### 9.2 题库考试引擎（新文件 exam.js）
- 五种题型组件：**图片选择**（大场景 SVG 热区，点击放大局部，正确/干扰热区，考核模式无高亮）、**文字选择**、**填空**（关键字判定，允许同义）、**问答**（要点召回判分：知识库检索命中要点数 → 得分，界面标「判分结果由教练确认」）、**对话式语音沟通**（学员说/输入一句 → 系统按知识库召回作答或追问，类客服；语音识别联网可用、离线文字）；另加**拖动操作**（手柄拖到全开）作为图片选择题的变体。
