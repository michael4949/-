## 产品形态
1. **本届展示场景＝倒闸操作**（曾有"组网"口径，已作废）。学员扮演操作人；监护人视角在入口保留但标注"下一版本开放"。
2. **对话才是中心，设备只是道具**：陪练舱 v2 布局＝左 44% 数字人 + 右 56% 对话气泡流；作业面板是底部抽屉（Sheet），需要手指/执行/回报的节拍自动升起，标√后收回；抽屉打开时数字人自动缩小不被遮挡。
3. **教学引导性是硬要求**：三种模式（教学/演练/考核）、常驻任务指令条（分步打勾）、知识点卡（仅新主题自动展开）、三级提示（留痕扣分不阻断）、九主题知识地图、阶段预习卡、首次七步导览、教学模式下监护人带路（自动切位置）+ 同类错误首次只提醒不判违规。
4. **五拍闭环**是产品的业务灵魂：唱票 → 手指口述 → 对，执行 → 执行 → 检查回报 → 标√。缺任何一拍都要有判定。
5. 六处红线已埋并回归验证：未验电合地刀（一票否决+Canvas 弧光事故推演五段后果链）、异常未中止、跳项、走错间隔、GIS 只看后台、第 9 项票令陷阱（调度故意念错）。异常处置支线：中止→汇报值班负责人→逐级上报→研判→恢复。
6. 八种练习方式：完整票 / 三段分段 / 专项（验电接地、GIS 四项核对、接令与票令核对含陷阱）/ 错题重练（localStorage xwt_lastvio）。分段与专项会预置设备状态。
7. 评分＝六维雷达+否决项+加分项+能力标签+生成式复盘（genReview 引用本场真实数据）；完整成长曲线、学习地图、岗位胜任度放「评分复盘/成长档案」页做。
8. 底座证据页清单与建设顺序：**工作台 Dashboard → AI 教练中心 → 评分复盘 → 成长档案 → 教练编辑器（重点演示"从操作票一键生成剧本"）→ 班组看板 → 知识课堂接入**。
9. 「场景商店」这个名字不用，改为体现"很多可选的智能陪练教练"（AI 教练中心），预设大量不同类型教练以显底座丰富完整。

## 数字人
10. 数字人**改用 HeyGen**，背景**透明通道 WebM**；渲染由用户自行在 HeyGen 侧执行（形象用 AI 生图，提示词已交付：中年男监护人为主角+女调度员+男值班负责人）。
11. 播放层三档已定：clips（预渲染，主用，离线）/ stream（实时，联网自由问答）/ builtin（SVG 兜底）；任何环境不出空画面。
12. 旧 WebM 端点不支持自定义形象 → heygen-kit.js 走 v3（output_format:webm）优先、自动回退 v2（background:transparent）；形象需带抠像（matting）训练，`node heygen-kit.js looks` 可查。
13. 内置 SVG 数字人的口型＝拼音→十种视位、每字两帧（声母闭合/韵母开口）与语音逐字对齐；这套「同源驱动」指示条保留，是技术展示点。
