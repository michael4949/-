## 六阶段陪跑（验收节奏）
8/14 需求澄清 → 8/21 技术方案 → 8/28 需求冻结与初版演示 → **9/4 中期评审** → 9/11 预验收（线上）→ 9/23 交付与模拟答辩。
验收结论只有三种：通过 / 整改后通过 / 暂不通过。

## 演示范围方法论（「五个一」）
一个主要使用者、一个核心场景、一条完整流程、一个突出亮点、一个价值结果。
- 项目一：变电运行操作人 / 倒闸操作陪练 / 接令→操作→汇报→评分复盘（可分段 8 分钟演完）/ 数字人监护人主导五拍闭环与红线后果推演 / 全程留痕生成六维评分与复盘报告。
- 项目二：供电所班组长 / 月度班组管理（备会、查数、写总结）/ 打开画像→提问→班前会初稿→月度总结初稿→确认 / 一屏画像与即问即答 / 一份可直接修改使用、来源数据可追溯的月度总结初稿。

## 评分维度（作品往这上面靠）
创新性、技术水平、业务价值、实施效益、推广价值、展示效果。

## 客户现有系统基线（不要低于它）
南网「人工智能知识课堂」网上学院已有"我的陪练"：竞岗面试陪练（写实数字人三人面试官、分段倒计时、语音表现分析、二级指标环形图、逐题点评）与营业员业务陪练（3D 卡通双人数字人、可选陪练身份、多轮自由对话、得分环比、六维雷达、课程推荐）。我们的差异化：**对练＝操作+对话（五拍闭环），不是纯问答**；红线一票否决+后果推演；底座可从一张操作票生成新剧本。

## 主次关系（客户明确，不可颠倒）
把南网「人工智能知识课堂」**融入**「AI 智能陪练底座」——底座是主体，知识课堂作为课程/题库/学时/学员画像的供给层被底座调用（学时回写）。不是把陪练挂进知识课堂。
