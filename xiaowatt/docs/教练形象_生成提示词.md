# AI 教练中心 · 18 位虚拟教练形象生成提示词

## 使用方法

1. 在图片生成平台（即梦 / 通义万相 / Midjourney 等）逐条生成，**每条提示词 = 「风格总规范」+「该教练个体描述」拼在一起**。
2. 生成规格：**1:1 正方形，≥ 512×512**，PNG 或 JPG。
3. 按下表文件名存入 `xiaowatt/assets/coaches/`（如 `daozha.png`），运行 `python3 build.py` 自动内联到单文件，教练卡头像即替换为形象图。
4. 全部人物均为虚拟形象；提示词已避开真实 logo 与真实人物特征。同一平台、同一风格词、尽量同一批次生成，保证系列一致。

## 备选风格（如三维卡通不合意，换掉总规范里的第一句）

- 写实商务风：`超写实企业形象照，专业摄影棚灯光` —— 更庄重，但生成人脸一致性风险高
- 扁平插画风：`现代扁平风格企业插画人物半身像，简洁几何色块` —— 最耐看且批量一致性最好，略显年轻化

建议优先三维卡通（与数字人监护人的视觉气质衔接最顺），一次生成 4 条先看效果定风格，再批量出满 18 条。
