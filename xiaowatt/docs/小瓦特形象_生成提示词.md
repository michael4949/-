# 小瓦特 · 形象生成提示词

小瓦特同时出现在两个项目里（项目一工作台的「小瓦特今日提醒」、项目二「小瓦特·班」的主角），形象必须一致，并且要能做出"说话 / 思考 / 看东西 / 动手 / 倾听"五种状态。

## 使用方法

1. 在图片生成平台（即梦 / 通义万相 / Midjourney / 可灵等）先生成**主图**，满意后用同一张图做**四张状态变体**（图生图或角色一致性功能）。
2. 规格：**1:1 正方形，≥ 1024×1024，PNG 透明背景最好**（没有透明就用纯浅色背景，程序会裁圆）。
3. 按下表文件名放到 `xiaowatt/assets/xiaowatt/`，运行 `cd banzu && python3 build.py`，形象自动内联到单文件；没有图时程序用内置占位。

| 文件名 | 状态 | 用在哪 |
|---|---|---|
| `main.png` | 主图 · 待命 | 右栏头像、所有默认状态 |
| `talk.png` | 说话 | 她开口口播、回答时 |
| `think.png` | 思考 | 思考流出现时 |
| `look.png` | 看东西 | 认照片、审票、照亮台账时 |
| `work.png` | 动手 | 光标填单、排班、写文稿时 |
| `listen.png` | 倾听 | 麦克风录音时（可用主图代替） |

## 方向 A · 3D 吉祥物（推荐）

推荐理由：吉祥物更容易做出五种状态的表情与动作，也不会与项目一的 18 位真人教练形象混淆。

### 四张状态变体（同一角色，外形、配色、安全帽完全一致）

| 文件 | 描述（接在主图提示词后） |
|---|---|

| `think.png` | 思考：眼睛看向右上方，一只手托着下巴，头顶闪电标志微微发光，屏幕脸上有三个省略号光点 |

## 方向 B · 数字人助理（备选）

> 一位名叫"小瓦特"的年轻女性数字人助理，25 岁左右，东亚面孔，短发利落，表情亲切聪慧，身着南方电网深蓝色工装式衬衫，左胸有小小的金色闪电徽章，佩戴细框耳麦，背景为浅色的供电所办公室虚化；写实 3D 渲染，柔和影棚光，正面半身，居中，高清，无文字。

与项目一的 18 位教练形象区分：她不戴安全帽、不拿工具，气质是办公室助理而非现场作业人员。状态变体同上（说话 / 思考 / 看 / 动手）。

## 注意

- 全部为虚拟形象，提示词已避开真实 logo 与真实人物特征；不要在图里出现任何文字或公司标识。
- 同一平台、同一批次生成，保证五张图一致；如平台支持"角色参考 / 一致性"功能，优先使用。
