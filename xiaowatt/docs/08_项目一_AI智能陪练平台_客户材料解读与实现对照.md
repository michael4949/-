## 二、场景一 · 操作票填写（技能水平）

### 题目界面

按总体方案 3.4「上信息、下作答」实现四段：

1. 操作任务与作答要求（照录试卷原文）
2. 主接线图：110kV 仿真站，考核Ⅰ线1161 间隔画全（1161 开关、11611 / 11614 刀闸、116140 / 1161B0 / 1161C0 地刀），16 个设备可点开看名称、编号与当前状态
3. 运行方式说明 5 段 + 操作说明 + **必要的空气开关与压板编号** 5 个屏柜（66P 保护屏、就地控制柜、40P 测控屏、智能柜、70P 备自投屏）
4. 逐项写票表：一项一个输入框，支持主 / 子项，子项自动编为 x.1、x.2

场景只给完成写票必须知道的信息：不给标准步骤顺序、不给标准答案全文、不给「哪一步必须先做」的结论。

### 判卷

顺序固定为 **步骤匹配 → 状态阶段 → 换序 / 特殊顺序 → 漏项 → 文字 → 危险规则**，规则全部来自《操作票结构化标注确认表》70 行业务确认：

- **不逐行死比**：先认出学员这句话对应标准票哪一步（关键字 + 动词 + 文本相近度；同名步骤如「汇报调度」按位置取首个未用），再判断放在当前位置是否合法
- **状态阶段**：阶段A 运行→热备用（1–14）、阶段B 热备用→冷备用（15–25）、阶段C 冷备用→检修（26–48）；上一阶段必要操作未完成就出现本阶段受限操作，判阶段越界，与普通换序错误区分
- **可换序组**：13 个组，业务确认可换序的组内顺序不同不判错、不扣分
- **特殊顺序**：只锁业务标注明确写出的关系（必须在 X 之前 / 之后 / 紧贴 X 之后 / 必须作为 X 的子步骤 / 最后一步）
- **漏项**：优先按该步骤的漏写处理执行，不因缺失造成后续行错位而重复报顺序错误
- **文字三档**：严格一致 / 仅关键字严格 / 允许规范等价表达，分别执行
- **危险操作**：优先级最高，命中直接整票不合格并计 0 分，扣分前得分仍展示
- **去重**：同一根本错误只计一次

六种典型答卷的判卷结果（`node v2plat.js` 可复现）：

| 答卷 | 结果 |
|---|---|
| 按标准票填完 | 100 分，无错误 |
| 组内换序（7/8、17.1/17.2、32/33 互换） | 100 分，无错误 |
| 先拉母线侧刀闸 | 97 分，仅 1 条顺序错误，不连锁 |
| 漏写 4 项（11、19、31.3、47） | 92 分，4 条漏项，无连锁顺序错误 |
| 并项 + 缺双重名称 | 97 分，1 条文字不规范 + 1 条漏项 |
| 未验明无电压即合地刀 | 整票不合格，计 0 分（扣分前 96） |

### 错误解释

每条错误输出九要素：错误类型、错误位置、对应标准步骤、正确要求、为什么错、**业务执行原因**、**依据文件 + 条款编号 + 条文正文**、建议写法、处理结果。

- 业务执行原因来自标注表；标注表为空的步骤显示「执行原因待业务补充」，不由模型生成正式业务事实
- 制度依据检索优先级按《ai 参考文件优先级》：安规及释义 → 电气操作导则 → 其他。条款库收录 19 条真实条文，例如安规 6.3.1「接地前应先验电」、6.3.8「间接验电应有两个及以上非同样原理或非同源的指示」、6.2.3「应断开停电设备各侧断路器、隔离开关的控制电源和合闸能源」；导则 4.5.4 停电检修的隔离与接地顺序、6.1.18 操作票应填写的项目、6.1.8 不得并项、6.1.20 主子项、6.1.19 汇报调度与再经调度令
- **检索不到时返回「未找到足够明确的制度依据，建议人工复核」**，不编造文件名、条款号、条文正文

### 开发边界的落实

- 扣分值做成配置项，界面上写明「分值为业务规则配置项」，程序不写死
- 危险操作只实现业务已确认的 4 条（第 9、15、26、27.1 项漏写即整票不合格；未验明无电压即合地刀；带负荷拉刀闸；带电合地刀），完整清单留配置入口
- 标准票发布后冻结，版本号随答卷保存，历史答卷用当时版本复现

## 三、场景二 · 专家选聘答辩（通用能力）

技能专家口径。数字人评委按《答辩通用问题参考》六类提问：作用发挥、系统思考、创新精神、计划与控制、沟通协调、风险管理与合规性；每场抽 5 题。

打分按三类指标：

- **硬性**：关键词命中、合规红线（出现「先干了再说」「没出过事」「瞒报」等即重扣并提示）、流程步骤（情境—任务—行动—结果四段结构）
- **软性**：表达（篇幅）、共情（对方视角）、逻辑（层次连接）、情绪
- **结果**：任务是否达成（量化结果）、是否满意

折算到《专家选聘面试答辩评价标准》：核心能力实用性 40 / 先进性 30 / 创新性 30，招标竞聘必要性 20 / 可行性 45 / 价值性 20 / 创新性 15，逐项给优秀 / 良好 / 一般分档并附标准原文。再映射到通用能力五项。输出逐题点评 + 亮点 + 改进。压力模式下评委会就薄弱处追问。

陪练 AI 七项可定制：性别、性格、年龄、教育背景、角色身份、情绪状态、语言风格。
