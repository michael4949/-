# 班组长 PPT V4.0 视觉重设计方案（10/2，用户提供 35 张 202 厂海报作参照）

参照图存 `docs/参考/PPT视觉参考_202厂海报/`（b1–b7 共 35 张：31 张竖版 1333×2000 海报 + 4 张横版 2000×886 幻灯片）。本方案 = 对参照图的拆解 + 迁移到客户《附件3-2》模板骨架的约束 + 班组长 PPT 30 页逐页重设计。实施前逐页经用户确认。

## 一、拆解：35 张图共用的一套视觉语法

| # | 层 | 观察到的做法（像素级） |
|---|---|---|

| 9 | 版式骨架 | 左右双栏对照（传统 vs 新）；中轴（竖向红→绿渐变轴 + 节点）；左侧时间管道 + 右侧进度曲线；六边形蜂窝；三栏对照；上主图下分析。页边距约 2.5%，栏距 1.5%。 |
| 10 | 质感与层次 | 纸纹；卡片下 2–4px 柔影；铜金属渐变（#8E5A2B → #D9A86A → #8E5A2B 高光带）；蓝发光（#4FA3FF 外发光 12–20px）；箭头带铜色辉光。层次：底纹 < 面板 < 插画 < 标注 < 结论绶带。 |
| 11 | 横版四张 = 幻灯片化答案 | 顶部左右各一个色块页签（◆ 中文 · ENGLISH + 编号圆）；中央真实感主图 + 浮层数据卡；正文关键词红色 / 金色强调；底部深蓝横条放 4–5 个金色关键词句，两端圆形徽章（PHASE III / M6–M9 2026）。16:9 改法直接参照这四张。 |

共性结论：**它不是"炫酷"，而是"一张工程图纸的权威感"**——图纸底 + 铭牌编码 + 黄铜仪器 + 一个主体插画 + 大数字 + 一句结论。每页只讲一件事，用一个母题承载。

## 二、迁移到班组长 PPT 的约束

1. **骨架不动**：客户《附件3-2》模板的封面 / 声明 / 目录 ×5 / 汇报完毕 / 页眉标题 / 右上 logo / 页码保留；重做 21 页内容页 + 团队页。封面与结尾在模板版式上只加图纸底纹与铜色元素。
2. **色**：模板藏青 #002060 做主色（与参照一致）+ 铜金 #B8862B / #C9A227 做强调 + 米白图纸底 #F4F0E6；绿 / 黄 / 红只做状态；南网元素 = logo + 深蓝；不出现 CNNFC / 核工业 / 202 厂字样。
3. **字**：微软雅黑（评审电脑必有）；超大标题 微软雅黑 Bold 36–44pt；代号数字 Arial Black；英文副题 Arial 字距 +。不依赖安装字体。
4. **内容铁律**：文案延续 V3.0 已确认版本，只换表达形式；不出现内部标注、口语、空泛表述；脱敏。
5. **16:9 改法**：竖版"上标题 — 中主图 — 下页脚三件套"改为"上标题导语 — 中内容（主图 + 铭牌）— 底一行（左 KPI 三格 + 右结论绶带）"；图签条不要（模板已有页码 / logo），改为底行右端一枚小徽章（如 "V4.0 · 2026-10"）。
6. **制作方式（三层）**：① 贴图层——图纸底、切角框、铜徽、管道、仪表、蜂窝等由 HTML/SVG 经 Playwright 渲染为 PNG（沿用 `docgen/pptkit/render.cjs` 流水线）；② 文字层——全部原生可编辑文本框；③ 截图层——demo 截图裁切装进"设备屏 / 铭牌"框。**整页用图像模型生成不可取**：参照图里已见错字、乱码，参赛文字必须准确可改。
7. **人物 / 场景插画**：由用户用图像模型按本方案的提示词生成（无文字、米白底、蓝图线稿背景、深蓝工装、不带任何 logo），或先用程序化线稿占位；每页 1 张，30 页约 18 张。

## 四、实施路径

1. 先做 1 页样板（建议第 19 页派工页或第 22 页对比页）确认视觉；通过后批量。
2. 新建 `docgen/gen_ppt_banzu_v4.py`（仍基于 `ppttpl.py` 骨架）+ `docgen/pptkit/bp.html`（图纸底 / 切角框 / 铜徽 / 管道 / 仪表 / 蜂窝 / 曲线的 HTML·SVG 素材）→ `render.cjs` 出 PNG → python-pptx 贴图 + 原生文字。
3. 插画提示词按页给出；没有插画的页先用程序化线稿，不空着。
4. 每页出图后用 LibreOffice 渲染自检，再发预览。
