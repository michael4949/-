# 小瓦特·班 · 供电所班组长 AI 助手（项目二工作区）

业务方：光明供电局（联系人林洁怡）。权威规格＝`../docs/正式交付物/` 两份班组文档（需求 V1.0 / 技术 V1.0）+ 甲方 9/3 定稿的设计方案 v0.5（"v0.3 布局，每次点击换来一段看得见的 AI 过程，鼠标为主语音为辅"）。本文是开发视角的浓缩。

## 一句话定位

一位有形象的班组长助手「小瓦特」，坐在班组台账和能力图谱之上，替供电所班组长看、想、写、办、记。**页面是舞台，班长照常点按钮，每一次点击之后屏幕上出现的是她在做：照片上框一个个亮、人员条带自己过滤排序、光标飞到表单里一格格填、文字一段段长出来。** 所有涉及人的结论固定标注「由班组长确认后使用」。

## 三条原则（甲方 9/3 确认）

1. **点击是班长的手，动画是小瓦特的手。** 结果是过程的尾声，不直接跳结果。
2. **能点的东西都会"回应"。** 人名可点（她解释）、数字可点（她照亮台账那几行并逐行念）、照片可点（她重新认）、文稿段落可点（她只重写那段）。不做折叠面板、出处芯片、时间线、计数器、AI 工作报告。
3. **语音是快捷键，不是入口。** 命令栏与对话框各一个麦克风；说完先复述再办；所有语音路径都有等价的点击路径；演示只用一次语音。

## 人员评价三类等级（`data3.js`）：绩效 / 岗评 / 技能，依据都指到台账

- **绩效考核（季度）**：五类考核内容加权 100——安全生产 30、任务完成 25、工作质量 20、学习培训 15、协同创新 10。分值从台账算：违章记录（严重扣 30、一般扣 12）、任务台账完成率与超期、本周工时超班组约定扣 8、两票退回扣 15、巡视发现缺陷加 6、学时进度与考试均分、带教与案例经验。等级 优秀 / 良好 / 合格 / 待改进。
- **岗位胜任评价（岗评）**：对照岗位说明书 `POST_REQ` 四类——资质准入（应持证 vs 实持）、专业知识（图谱模块底线）、技能操作（实操 ≥ 80）、安全履职（无严重违章）。结论 胜任 / 基本胜任 / 待提升，未达标项直接变成培养重点。
- **职业技能等级**：`SKILLS` 认定台账（等级、取证时间、鉴定成绩、认定机构）+ `SKILL_YRS` 申报年限，给出距下一级还差多久、够不够岗位要求，够条件的可直接报名。
- **班组资质盘点** `certGap()`：五类证书持证人数对 `CERT_NEED` 作业下限，算缺口并按"年轻优先、已有登高证优先"挑培养人选；`trainFocus()` 把资质缺口、图谱最弱模块、学时落后合成下次培训重点。
- **年龄与梯队** `ageStruct/ageIn/certAge/ageRisk`：年龄分段与五年后推演、关键资质持有人平均年龄与 35 岁以下人数（少于 3 人或平均 ≥38 岁且无年轻人即判高风险）、骨干层年龄与补位人选、30 岁以下只有准入证的人。这几项就是"老龄化提前预防"的落点。
- **指标对照** `metricMap()`：画像上的八个数与台账中心同源，每个都能跳到对应台账核对。

## 状态层（`state.js` · `DB`）：所有数字由流程推导，不预设

页面只读 `DB.*`，按钮只写 `DB.*`：`jobs/addJob/setJob/removeJob`（任务与状态）、`dispatch`（写状态 + 起草工作票 + 通知 + 流水）、`start`（关口：工作票未审核不放行）、`report`（回传事件、连续小时、超三小时提醒）、`finish`（写工时台账 → 本周工时条 / 派工阈值随之变化；人员回岗；工作票转已执行；关联缺陷转待验收）、`close`（缺陷关闭并记验收人）、`hours/week/status`、`notices/notify`、`defects/setDefect/flow/stageOf`、`tickets/addTicket/putTicket/setTicket/ticketM`、`progressAll`、`weekPlan/setWeek`、`taskLedger/typeCounts/month`（月度汇总）、`log/logs`（操作流水，工作日志与班后会纪要取数）。`MONTH` 是 `DB.month()` 的代理。上传两票的读取与审核在 `upload.js`（`UPLOAD.read/parse/audit/fix`，zip + `DecompressionStream('deflate-raw')` 离线读 docx/xlsx）。样例票在 `samples/`（`gen_samples.py` 生成：规范一张、待审一张含四处问题，Word / Excel / 文本三种格式）。

## 验收

1. 八分钟演示只用鼠标可走完；语音只在两个麦克风处出现且都有等价点击路径。
2. 每个决策卡按钮点击后两秒内出现可见过程（条带 / 思考流 / 光标填单 / 逐字写），不直接跳结果。
3. 对话与卡片里带下划线的数字可点，台账滑出并逐行照亮，累加与她的话一致。
4. 照片核对时框逐个出现并有旁白，拿不准的项红框并提问。
5. 文稿逐段流式、有取数停顿；六类修改指令只重写对应段落，新旧可见。
