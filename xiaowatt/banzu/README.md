# 小瓦特·班 · 供电所班组长 AI 助手（项目二工作区）

业务方：光明供电局（联系人林洁怡）。权威规格＝`../docs/正式交付物/` 两份班组文档（需求 V1.0 / 技术 V1.0）+ 甲方 9/3 定稿的设计方案 v0.5（"v0.3 布局，每次点击换来一段看得见的 AI 过程，鼠标为主语音为辅"）。本文是开发视角的浓缩。

## 一句话定位

一位有形象的班组长助手「小瓦特」，坐在班组台账和能力图谱之上，替供电所班组长看、想、写、办、记。**页面是舞台，班长照常点按钮，每一次点击之后屏幕上出现的是她在做：照片上框一个个亮、人员条带自己过滤排序、光标飞到表单里一格格填、文字一段段长出来。** 所有涉及人的结论固定标注「由班组长确认后使用」。

## 三条原则（甲方 9/3 确认）

1. **点击是班长的手，动画是小瓦特的手。** 结果是过程的尾声，不直接跳结果。
2. **能点的东西都会"回应"。** 人名可点（她解释）、数字可点（她照亮台账那几行并逐行念）、照片可点（她重新认）、文稿段落可点（她只重写那段）。不做折叠面板、出处芯片、时间线、计数器、AI 工作报告。
3. **语音是快捷键，不是入口。** 命令栏与对话框各一个麦克风；说完先复述再办；所有语音路径都有等价的点击路径；演示只用一次语音。

## 工程

```bash
cd banzu && python3 build.py     # → dist/小瓦特班_班组长AI助手_高保真原型.html（纯标准库）
node smoke.cjs                   # 冒烟：60 余项断言 + 10 张截图到 shots/，期望 FAILS 0 ERR none
```

- 拼接顺序：data.js → xw.js（引擎）→ comp.js（派工条带 / 照片识别 / 文稿流式 / 审票 / 值班表）→ charts.js（手绘 SVG 图表：环形 / 横向条 / 折线面积 / 雷达 / 到期时间轴 / 计量条，悬停提示 + 点击下钻到台账聚光或她的回答；类别色 CPAL 六色固定顺序，已过色盲与对比校验）→ app.js（框架、路由、委托、讲师演示台）→ p_home / p_people / p_sched / p_safety / p_train / p_doc / p_know / p_ledger → intent.js（意图路由 XW.ask）。
- 小瓦特形象：`../assets/xiaowatt/main.png`（甲方 9/3 提供的 3D 全身形象，已抠透明底 640px）已内联，右栏与晨间横幅用全身像，状态靠光晕颜色与动作动画（说话点头 / 思考侧身 / 看东西前倾 / 动手左右挪）；`talk/think/look/work/listen.png` 存在即按状态换图。左栏为毛玻璃菜单 + 立体渐变图标（SVG 线性图标）。提示词见 `../docs/小瓦特形象_生成提示词.md`。
- 运行时钩子：`window.__XW_SPEED`（时长倍率，测试用 0.03）；讲师演示台可切语速、重播晨间简报、清空本机记录、跳页。
- 配色：浅色底 + 靛蓝 AI 体系（bg #f8f9fe / 主色 #5a5bf0→#9a4dff / 绿 #18b97a / 琥珀 #d97706 / 红 #e5484d / 青 #00a8c6），客户 logo 原样置于浅色底，不反白。

## 验收

1. 八分钟演示只用鼠标可走完；语音只在两个麦克风处出现且都有等价点击路径。
2. 每个决策卡按钮点击后两秒内出现可见过程（条带 / 思考流 / 光标填单 / 逐字写），不直接跳结果。
3. 对话与卡片里带下划线的数字可点，台账滑出并逐行照亮，累加与她的话一致。
4. 照片核对时框逐个出现并有旁白，拿不准的项红框并提问。
5. 文稿逐段流式、有取数停顿；六类修改指令只重写对应段落，新旧可见。
6. 当场改一次人选，下一次同类派工她主动提起；改一次措辞，下一份文稿沿用。
7. 人物全部虚拟；能力与资格结论均标"由班组长确认"；grep「演示|待建|下一版本|比赛|评委|一期」零命中（讲师演示台除外）。
8. 需求文档 V1.0 的七条（六类信息一屏可下钻、成员画像卡、助手三问、班前会初稿、月度总结与画像数据一致、输出尾注、数据脱敏）全部覆盖。
