# 小瓦特·班 · 班组数字画像与班组长 AI 助手（从零搭建）

业务方：光明供电局（联系人林洁怡）。权威规格＝`../docs/正式交付物/` 两份班组文档（需求 V1.0 / 技术 V1.0），本文是开发视角的浓缩。

## 一句话定位
把散落在多系统台账里的班组信息聚成**一屏画像**，配一个**可对话助手**，替供电所班组长做三类事务：**查数、备会、写初稿**。所有输出都是初稿与参考，**由班组长确认后使用**——这行字是产品的一部分，每个输出尾部固定出现。

## 业务问题（文案与功能都从这里出发）
- 资质证书、学时、考勤、任务、安全活动分散在多个系统台账，掌握全貌要逐处查看；
- 班前会材料、月度总结靠手工汇编，占用工余时间；
- 证书复审、学时达标靠个人记忆跟踪，缺统一入口。

## 使用人员
主要使用者＝供电所班组长；相关＝班组成员（被画像对象，全部脱敏虚拟）、所管理人员（多班组总览）、人力资源部（规则口径）。

## 功能规格

### 1. 班组画像（一屏总览）
六类信息，图表类型不重复、均可下钻至成员明细：
人员结构 / 资质有效性（含临期高亮）/ 学时完成 / 安全活动 / 任务执行 / 荣誉。
另有：成员画像卡（点人名弹出）、临期与待办提示条（证书复审、学时缺口）。

### 2. AI 助手（对话式）
- **即问即答**：结构化数据查询，示例三问必须答对——「三个月内证书到期的有谁」「本月学时未完成的名单」「下周检修任务谁去合适」（第三问给人选参考+理由，明示"安排由班组长决定"）。实现＝规则化查询+模板作答，答案带数据出处（哪张台账哪个字段）。
- **班前会材料初稿**：当日安排/风险提示/学习内容三段，一键生成，可编辑。
- **月度总结初稿**：按当月画像数据生成（人员、学时、任务、安全活动、荣誉各一段），数字与画像页一致、可追溯。
- **待办提醒**：临期证书、学时缺口自动汇成待办列表。

### 3. 所级管理视图
多班组画像总览（不做排名，不写"排名"二字），点击进入单班组画像。

## 数据（gen_banzu.py 造数，全部脱敏虚拟）
一个班组 12 人：姓名（虚拟）、岗位、工龄、证书（名称/取得时间/复审期限，造 2-3 人三个月内临期）、学时（要求与完成，造 3 人未达标）、出勤值班、任务记录、安全活动、荣誉。真实接入口径：评优后按数据管理要求另行确定——这句话进技术文档不进 UI。

## 边界（红线）
- 人员评价与资格判断仅供参考，结论由人确认（UI 固定标注）。
- 不接生产系统、不用真实人员数据。
- 不做绩效自动评分、不做移动端、不做考勤原始采集。

## 验收 7 条
1. 总览一屏六类信息齐全，每类可下钻到成员明细；
2. 成员画像卡可打开；
3. 助手正确回答三类示例问题（名单/统计/临期）；
4. 班前会初稿要素完整（当日安排/风险/学习）；
5. 月度总结与画像数据一致；
6. 每项 AI 输出尾部标注「由班组长确认后使用」；
7. 数据全脱敏虚拟。
