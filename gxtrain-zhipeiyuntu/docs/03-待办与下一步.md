客户尚未看到具体投入。需要交付四件：

报价表规则（硬性）：
- 直接给底价一个数，不给区间价、不给分档价
- 以功能模块为计价单位（知识资产中枢 / 课程工厂 / 智能陪练 / 问数助手 / 成长地图 / 千人千面计划 / 课程体系）
- 报价表任何位置不得出现「人天」，包括边界条款里的「约 X 人天」，一律折算为金额
- 面向领导的版本要写清：投多少钱、解决什么问题、达到什么效果、ROI 是多少，不要写技术细节

## 环境提示

打包脚本 `bundle-artifact.sh` 是外部工具链带的，本仓库未包含。等价命令：

```bash
npx parcel build index.html --dist-dir dist --no-source-maps
npx html-inline -i dist/index.html -o bundle.html
```

若 pnpm 报 `ERR_PNPM_IGNORED_BUILDS`，执行 `pnpm approve-builds` 或 `pnpm config set dangerouslyAllowAllBuilds true`。

`tsconfig.app.json` 已加 `"ignoreDeprecations": "6.0"`，去掉会报 TS5101。
