## 背景照片

`src/data.ts` 顶部：

```ts
PHOTO      = 'https://commons.wikimedia.org/wiki/Special:FilePath/Nanning%20Wuxiang%20New%20Area.jpg?width=2200'
PHOTO_ALT  = 'https://i2.chinanews.com.cn/...（广西电网 220kV 盘岭送变电工程实景）'
```

`Hero.tsx` 三级兜底：PHOTO → PHOTO_ALT → 内置 `CityArt()` 实景插画（邕江两岸天际线、喀斯特峰林、滨江绿带、斜拉桥、江面行船、跨江输电通道）。

照片处理方式（不可改成整体压白）：
- 照片占下方 78%，`objectPosition: center 55%`
- 纵向渐变：顶部 0–25% 融入天空，中段 36–62% 完全透明保持照片本色，底部 78–100% 压深
- 标题区单独一层径向柔光
- 卡片用 `rgba(255,255,255,.9)` + `backdrop-filter: blur(4px)`

若客户提供自有高清图，只替换 `PHOTO` 即可，版式不动。

## 元素库（`src/deco.tsx` + `src/scenes.tsx`）

**南网**：`GridMark`（六边形电网标识）、`Tower` / `PylonS`（输电铁塔）、`PowerCorridor`（输电走廊，导线垂弧 + 电流光点）、一次接线画法（母线 / 刀闸触头 / 断路器 / 接地刀闸）

**广西**：`GuangxiMap`（轮廓 + 14 地市局按真实方位 + 骨干通道流动 + 南宁金色扩散环）、`BronzeDrum`（铜鼓太阳纹，12 芒纹 + 联珠圈，慢转 + 外环脉冲）、`BrocadeStrip` / `BrocadeLine` / `.brocade`（壮锦菱形纹）、`Karst`（喀斯特峰林）

**人力资源**：`TalentLadder`（五级技能等级柱 + 人形）、成长阶梯与登阶人形（MapScene）、`Person`、组织树、技能等级证书

**AI**：`AIBrain`（点阵大脑 + 神经连线流动）、`NeuralNet` / `NeuralBlock`（四层网络 4-6-6-3，脉冲逐波前传）

### 模块专属

- **陪练一次接线图**：母线与带电段红色电流光点持续流动；开关合闸时本体呼吸；地刀合上后扩散脉冲；状态牌（运行/热备用/冷备用/检修）微呼吸；数字人当前发言者金色扩散环 + 口型动画
- **课程工厂**：六步生成进度逐步点亮 + 打字光标
- **问数助手**：脉冲检索提示 + 流式出字
- **成长地图**：雷达由中心展开、六顶点交替放大；矩阵格波浪浮现
- **计划引擎**：四步点亮 + 权重条生长

## 陪练舱数据结构（改动最频繁的部分）

剧本在 `src/coach/script.ts`，由客户提供的参考原型剧本替换为广西口径后生成：

```ts
STEPS: Step[]   // 30 步，每步 { no, phase, loc, act, target?, ticket, call, recite, order?, report?, rule, why, redline?, trap?, vd? }
                //   loc 取 phone/wufang/hmi/bay/p8/p20/cab 七个作业位置；act 为 tap/hold/select 等交互动作
                //   ticket 为票面文字，call 为唱票，recite 为复诵，rule/why 为规程依据与原因
                //   redline 标记红线项（带电合地刀 / 异常未中止），trap 标记票令陷阱，vd 标记验电项
RISKS           // 12 条风险辨识 [名称, 措施, 后果]
WUFANG          // 五防模拟 4 项
KNOW            // 知识地图 9 个主题
PREVIEW         // 三个阶段的预习
STEPKP          // 每步知识点卡
```

人物、教练目录、计划、维度与看板数据在 `src/coach/data.ts`：`CHARACTERS`（黄志远 监护人 / 韦岚 南宁地调 / 覃建国 值班负责人）、`COACHES`（38 个教练，`unit` 字段覆盖全部单位组，`avatar` 复用 21 幅形象）、`PLANS`（完整票 / 三个分段 / 三个专项 / 错题重练）、`DIMS6` / `DIMS10`、`TEAM`、`COMPANY_BOARD`（28 个单位）。

引擎在 `src/coach/engine.ts`：模块级状态 `S` + `bump()` 通知，界面用 `useSyncExternalStore` 订阅；`speak()` 返回按字数计时的 Promise，驱动数字人姿态与字幕；阶段 fill → prep → wufang → run → end；五拍 唱票 / 手指口述 / 对，执行 / 执行 / 检查回报；`openReport()` 写入 localStorage（键 `zpyt_*`）。

## 视觉体系（2026 版）

- 令牌在 `src/index.css`：`--indigo` 靛蓝主色，`--ai` / `--ai-2` / `--violet` AI 强调，`--gold` / `--gold-2` 金色重点，`--glass` 玻璃面板底色，`--r` 圆角 14px，`--shadow` 柔和投影
- 页面底：多层径向渐变 + `src/Ambient.tsx` 背景动效层（光晕漂移、微粒缓升、呼吸圆环、掠过光带），首页在实景照片之上叠加同一层
- 面板 `.panel` 玻璃质感；按钮 `.btn` / `.btn-primary`（靛蓝到电光蓝渐变）/ `.btn-gold`；标签 `.tag` 胶囊；分段控件 `.seg`；关键数字 `.num-grad` / `.gold-grad`；AI 元素 `.ai-badge` / `.glow-ring` / `.shimmer`
- 导航：标识栏白色玻璃，菜单栏深靛蓝渐变，当前项为发光胶囊；模块标题栏用 `.seg` 分段胶囊切换功能
- 图表按容器真实像素绘制（`useWidth`），文字不随容器缩放变形

## 知识资产中枢与课程工厂的分级页面

分级壳在 `src/drill.tsx`（`DrillShell` / `useDrill` / `jumpTo`），中枢与课程工厂各自在 `nav.tsx` 定义 `Route` 联合类型、`ROOT_OF` 与 `labelOf`。以中枢为例：`Route` 联合类型定义全部页面，`ROOT_OF` 把顶部二级功能映射到一级页，`TAB_OF` 反查所属功能，`labelOf` 生成面包屑文字。`HubShell` 维护栈（push / back / goIndex / replace），页面切换用 `.hub-page` 的进入 / 返回两种过渡；面包屑右侧的三格进度显示当前层级。跨模块跳转用 `window.dispatchEvent(new CustomEvent('app:go', { detail: { node, tab } }))`，`App.tsx` 监听后切换页面。

数据在 `src/hub/data.ts`：`CORE_IN` 手工精选条目（含职能部门与直属机构），`genFromUnits()` 由 `units.ts` 的 180 个场景批量生成条款 / 步骤 / 诀窍 / 题目 / 案例；每条自动带引用关系、版本历史、质量评分。规程版本库 `DOCS`、入库批次 `BATCHES`、专家 `EXPERTS_ALL`、质量分类 `Q_CATS`、权限矩阵 `PERM`、检索意图 `parseIntent()` / `searchAssets()`。

课程工厂的数据在 `src/factory/data.ts`：`CORE_IN` 手工精选课程（生产与职能单位各有代表），`genCourses()` 由评估表 180 个场景生成课程，`QUESTIONS` 由中枢条目生成并逐题挂锚点，`buildDraft()` 按单位 / 岗位 / 课时 / 原料构建草稿，`lectureText()` / `slidesFor()` / `taskbookText()` 生成讲义、课件页与任务书；运行期草稿、试卷与新增课程放在 `store.tsx`。
