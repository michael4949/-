给接手本仓库的 Claude Code 看。开工前通读本文件与 `docs/` 三份文档。

## 一句话说明

「智培云图」是为**南方电网广西电网有限责任公司人力资源部培训科**做的**人才培养数智平台高保真原型**，单文件 HTML 交付，用于现场演示。我方以「广州力航培训」名义对接培训科陈科长。

## 构建与运行

```bash
pnpm install
pnpm dev                                    # 本地开发
bash scripts/bundle-artifact.sh             # 若无此脚本，用下方 parcel 命令
npx parcel build index.html --dist-dir dist --no-source-maps
npx html-inline -i dist/index.html -o bundle.html
```

产物 `bundle.html`（约 1.4MB，含 21 幅数字人形象图的内嵌数据），双击即可在任意电脑打开，无需联网、无需服务端。

技术栈：React 19 + TypeScript + Tailwind 3 + Vite（开发）+ Parcel 单文件打包。`pnpm lint` 使用 oxlint，`npx tsc -p tsconfig.app.json --noEmit` 做类型检查（`src/components/ui/**` 的报错可忽略）。
`src/components/ui/**` 是 shadcn 脚手架自带，本项目基本未用，可忽略。

### 视觉体系（2026 版）

浅色智能感：靛蓝主色（`--indigo`）、电光蓝与青作 AI 强调（`--ai` / `--ai-2`）、金色作重点（`--gold`）。页面底为多层径向渐变的网格底，所有面板走玻璃质感（`.panel`：半透明 + 背景模糊 + 14px 圆角 + 柔和投影），按钮与标签走胶囊与渐变（`.btn-primary` / `.tag` / `.seg`），关键数字用渐变文字（`.num-grad` / `.gold-grad`），AI 元素用 `.ai-badge` / `.glow-ring` / `.shimmer`。
每个模块页与首页之下铺一层 `src/Ambient.tsx` 背景动效：柔光晕缓慢漂移、微粒缓升、呼吸圆环、掠过的光带；底部主题动效带已全部拆除（`scenes.tsx` 的 `SceneRibbon` 保留但不再渲染）。新增页面只需使用共用类即可自动获得同一视觉。

### 分级导航范式（六个模块共用）

`src/drill.tsx` 的 `DrillShell` 提供路由栈、面包屑、层级指示、页面过渡、提示与跨模块跳转；`jumpTo(node, tab, route)` 触发 `app:go` 事件，`App.tsx` 把 `route` 作为 `init` 传给模块壳，实现跨模块深链（中枢条目的课件引用 → 课程工厂课程详情；成长地图的缺口 → 千人千面 IDP；计划条目 → 课程库 / 陪练中心；开班需求 → 课程体系）。再次点击当前功能标签会回到该功能的一级页。

### 六个已成型的深化范式

- **知识资产中枢**：八个一级功能（总览驾驶舱 / 资产目录 / 语义检索 / 智能入库 / 专家经验萃取 / 知识图谱 / 规程版本与影响 / 质量与权限），每个一级页都可下钻到二级、三级（目录 → 条目详情 → 引用清单 / 规程原文 / 版本对比；入库 → 批次 → 条目审核；版本库 → 版本详情 → 同步任务单；质量 → 问题清单 → 条目）。路由栈在 `hub/nav.tsx`，新增页面只需扩展 `Route` 联合类型、`labelOf` 与 `modules/Hub.tsx` 的 `render`。其余模块的深化按同一范式做。
- **AI 课程工厂**：八个一级功能（工厂驾驶舱 / 生成工作台 / 课程库 / 题库工作台 / 审核工作流 / 微课工作室 / 内训师工作台 / 效果分析），生成工作台按单位、岗位、课时与中枢原料真实构建课程草稿（`factory/data.ts` 的 `buildDraft`），产出物（大纲 / 讲义 / 课件页 / 微课脚本 / 实训任务书 / 试题）逐条回链中枢；课程库 → 课程详情 → 章节页 / 产出预览 / 学习数据；题库 → 题目详情 → 作答分析，智能组卷三项校验；审核 → 审核详情（AI 自检批注可一键采纳）→ 页级批注；微课 → 分镜 → 分镜编辑（数字人讲师形象复用陪练教练库）；内训师 → 档案 → 课程；效果分析 → 课程效果 → 修订任务。
- **智能问数助手**：八个一级功能（助手驾驶舱 / 问答工作台 / 提问热度榜 / 知识缺口 / 数据口径中心 / 助手技能 / 回答质量 / 渠道与嵌入）。问答引擎在 `ask/engine.ts`：意图识别 → 范围与口径 → 取数或检索 → 回答、图表、下钻、动作与追问；数据问答对任意单位、班组、个人与 12 项指标即时生效（`ask/data.ts` 的指标字典与 `metricValue`），知识问答走中枢 `searchAssets`，动作问答匹配技能并执行；多轮追问（"那 XX 呢"、"按班组看"、"近 12 个月趋势"）沿用上一轮指标与范围；每条回答带思考过程、置信度、口径卡、出处与溯源。会话在 `ask/store.ts`，下钻返回后对话仍在。标识栏搜索框直接进入问答工作台提问。
- **学习成长地图**：八个一级功能（地图驾驶舱 / 个人成长地图 / 单位能力全景 / 岗位能力模型 / 缺口与预警 / 人才梯队 / 成长轨迹 / AI 预测与干预）。数据全部由 `atlas/data.ts` 从岗位模型、单位规模与评估表推导：个人 → 能力项（12 个月走势、同岗位分布、证据）→ 证据记录，另有对比与晋级模拟；单位热力矩阵（28 个单位或 14 个地市局 × 六个能力领域）→ 单位详情（雷达、走势、班组排行）→ 班组（成员 × 能力项热力）→ 个人；岗位模型（能力项 × 等级要求线热力）→ 能力项定义；缺口九宫格（人数 × 差距深度）→ 缺口详情（根因、补齐预测曲线、方案）→ 人员清单；人才九宫格 → 人才池 / 关键岗位继任（培养时间线甘特）；新员工成长流向图与三届曲线 → 批次 → 节点；达标率预测带 + 驱动因子 + 干预模拟器（陪练频次 / 必修课 / 结对三个滑杆实时重算）→ 干预方案 → 单位落地。每级都有 AI 判读与可执行动作（下发陪练、写入计划、生成题目、经验萃取）。
- **千人千面计划**：八个一级功能（计划驾驶舱 / 计划生成引擎 / IDP 联动视图 / 需求汇总 / 排期与冲突 / 预算与投入 / 执行跟踪 / AI 优化与预测）。`plan/data.ts` 的 `personPlan()` 按成长地图缺口逐人生成条目（来源、得分、依据、学时、月份、状态）；引擎四步（权重滑杆 → 范围 → 五步 AI 排布动画 → 结果甘特）→ 单位结果 → 个人依据；IDP 12 个月甘特与季度卡 → 条目 → 完成证据；需求汇总（课程 × 单位组热力）→ 课程需求（14 个地市局分布、班次）→ 班次；场地 × 月甘特 + 月 × 周密度热力 + 冲突 → 班次 → 冲突处置（三选一方案）；预算科目环图 + 单位执行 → 单位预算 → 科目明细；执行漏斗 + 累计完成曲线 + 单位排行 → 单位跟踪 → 个人跟踪；年末完成率预测带 + 负荷散点 + 建议卡（采纳后预测实时更新）+ 参数模拟器 → 优化方案 → 单位落地。
- **课程体系（并入课程工厂）**：`factory/System.tsx`，三个主干项目 → 项目详情（分层覆盖曲线 / 产能 / 历期交付）→ 期次（学员构成、产出、评价）；十二门专题课 → 课程详情（地市局参训分布、历期）；开班日历 → 班次（报名来源、日程甘特、四项校验）。开班需求与排期同千人千面联动。
- **AI 智能陪练**：参照客户提供的「小瓦特·练」底座整体重做，人物形象全部保留，业务口径换成广西电网（南宁地调 / 广西中调 / 110kV 仿真站 / 培训三线 1163）。八个页面 + 公司看板，三种视角（学员 / 班组长 / 培训科）。

### 使用对象口径

平台使用对象是全部 28 个一级单位（17 个本部职能部门、6 个直属机构、14 个地市局、40 家县企、3 家产业公司），人力资源部自身也在其中。凡是涉及"覆盖范围""身份""单位"的地方都从 `src/units.ts` 取数，不要再写死"14 个地市局"。

## 硬性规则（客户已多轮明确，违反必须返工）

### 交互与视觉

1. **导航只能是顶部横版菜单 + 二级下拉**。滚轮缩放画布、中枢星盘、角色入口、分幕大屏、指令中心、培养主线、人才地图、双栏对照，这些都已被明确否决，不要再提。
2. **背景实景照片必须真实呈现**，不得整体压白遮罩把照片遮没。只允许靠局部处理保证文字清晰：标题区径向柔光、天空区顶部渐隐、底部压深。
3. **动效必须与页面结构和数据本身融合**。"在页面上漂几个图标"已被明确批评，禁止再用。
4. **动效要贯穿每一级页面**，不能只有首页有。
5. **原型中不得出现任何介绍式、讲解员式内容**。不要"交付物与报价口径""一期范围"徽标、"演示环境"标注、"点击××可下钻"这类导览提示。界面上每个字都应当是客户员工日常真实使用的系统里会出现的字。

### 文案表达（贯穿所有对话与所有交付物）

6. **坚决不用"不是……而是……""不……而……"这类先否定再肯定的句式**，只保留肯定部分，直接正面陈述。
7. 不用"手术""骨架""刀"，换中性词（调整、重构、框架）。
8. 不用"门禁"，改"关口""准入""把关"。
9. 命题与标题用正向表述（例："经验可传承"），避免"带不走"这类负面词。
10. 方案名称要有格调，不能把业务内容平铺成标题。
11. 面向客户高层的短消息与文案不用俚俗口语腔（"说白了""新玩法""新尺子"），用平实专业的陈述。
12. 不用自我问责 / 自证式表述（"保兑现""保守底线""参数可逐项质证复核"），改正向表述。
13. 报价类交付：不给区间价与分档价，直接给底价一个数；以功能模块为计价单位；报价表任何位置不得出现"人天"口径，包括边界条款里的"约 X 人天"，一律折算为金额。
14. 客户正式文档中不得出现写给我方看的过程性内容（版本对比、改了什么、修订说明、内部话术）。本 CLAUDE.md 与 docs/ 属于内部材料，不受此限。
