# 江铜真实生产排产系统 · 对标依据与 UI 落地映射

> 本文件记录"无限接近江西铜业真实系统"的联网调研依据，以及如何把真实
> 系统的**菜单 / 术语 / 工序 / 字段**落到三套界面，并标出 AI 赋能点。
> 调研时间：2026-06（演示数据均为示意）。

## 一、江铜真实信息化背景（用于品牌与框架对标）
- **江铜贵溪冶炼厂**已建成**国家"卓越级智能工厂"**，智能制造底座为 **用友（YonBIP）智能制造**；集团对外品牌 **"数智江铜"**。
- 贵冶**调度指挥中心**可监测全厂约 **10 万个点位**；冶炼加工领域已落地一批 **"AI+场景"**，官方表述风格为：**"铜酸智能协同""铁运智能编排""极板智能转运"**。
- 因此三套系统统一置于 **「数智江铜 · 智能制造平台」** 框架下；AI 赋能点命名沿用江铜"XX 智能 XX"的真实风格（如 **排产智能编排 / 齐套智能协同 / 铜耗智能核算 / 预测性预警**）。
- 台意（特种电工材料·镀锡铜线）与线缆厂属**铜加工板块**（非冶炼）；线缆厂 ERP 为 **鼎捷（DigiWin）**，采用 **鼎捷 APS + sMES + 互联中台** 体系。

## 三、铜加工真实工序与现场字段（用于资源行 / 工单表 / 工艺卡）
- **台意 镀锡圆铜线工艺线**：电解铜（阴极铜）→ **连铸连轧机组（CCR）** → **大拉 / 中拉 / 细拉** → **连续退火炉** → **镀锡线** → **复绕 / 分条** → 包装。
- **线缆厂工艺线**：拉丝 → **绞线** → **绝缘挤出** → **成缆** → **护套挤出** → 复绕 → 检验包装。
- **材质牌号**：无氧铜 **TU1/TU2**（软态 R / 硬态 Y，如 TU2R）、低氧铜杆、T1/T2；含氧量 ppm。
- **现场字段**：工单号、产品牌号+规格（mm/线径）、**炉号 / 批号 / 卷号(盘号) / 盘重(kg)**、数量(t/km)、客户、交期、机台、**模具**、班次、收线盘、优先级、齐套、状态。
- **工艺参数**：熔炼炉温 1175±5℃ / 保温炉 1145±5℃、拉丝速度、退火温度、镀层厚度 μm。

## 四、三个需求的 AI 赋能点（嵌入真实菜单内，江铜风格命名）
- **需求一（台意 · 数智江铜智能制造平台 / 用友 YonBIP 风格）**
  - 高级排产 APS → **排产智能编排**：小时级多目标寻优、Z+N 选线、急单插单、设备故障增量重排（人审后下发）
  - 齐套分析 → **齐套智能协同**：缺料预测 + 采购联动
  - 异常预警 → **预测性预警**：节拍偏差预测延期
  - 全局 **AI Copilot**：排产问答 / 解释 / 重排
- **需求二（台意端到端 · 做市商系统 + Oracle ERP）**
  - **智能报价**（实时铜价测算）· **智能评审**（关联模具/主辅料/产能）· 电子工艺卡参数推荐 · 排产智能编排 · 领料防错 · **铜耗成本智能核算**（推 Oracle 凭证）
- **需求三（线缆 · 鼎捷 APS + sMES 互联中台）**
  - **色谱智能编排**：最小化换色/换规格聚类 + 紧急插单（锁定关键交期单、日志溯源）
  - 齐套 + 采购申请联动（关联鼎捷 PR、未入库提醒）
  - **铜流智能核算**：理论用量 = 实际消耗 + 废料回收（闭环账平，凭证推鼎捷）
